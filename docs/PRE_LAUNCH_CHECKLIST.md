### เป้าหมาย
- ระบบบันทึกทรัพย์สิน / หนี้สิน / รายได้ / ค่าใช้จ่ายของ **ครอบครัวเดียว** → Net Worth รายเดือน (ทั้งครอบครัวและรายคน) · ปิดงวดเป็น Snapshot
- เจ้าของระบบไม่ใช่โปรแกรมเมอร์ → ทุกการเปลี่ยนแปลงอธิบายเป็นภาษาไทย (ศัพท์เทคนิคใช้ภาษาอังกฤษได้) + ขั้นตอนคลิก + เช็กลิสต์ทดสอบ
- ช่วงนี้: ปรับหน้าจอ / การทำงานทุกโมดูล + ทดสอบบนข้อมูล "เกือบจริง" → ล้างข้อมูล → Bootstrap ใหม่ (กำหนดวัน Go-live ใหม่) → AI นำเข้าข้อมูลจริง → Confirm Go-live

### วิธีทำงานที่ตกลงกัน (ทุกงาน)
- `git pull` ก่อนเริ่ม · แก้บน branch → เปิด PR ด้วย `gh api repos/accountoei/oeiwealth/pulls -f title=… -f head=… -f base=main -F body=@file` (GraphQL ใช้ไม่ได้) → เจ้าของกด Merge → Vercel deploy เอง
  - PR ที่แก้**เฉพาะเอกสาร** (`docs/`, `*.md`) AI Merge เองได้ แล้วแจ้งเจ้าของ
  - PR ที่ต่อจาก PR ที่ยังไม่ Merge: แตก branch จาก branch นั้น แล้วบอกเจ้าของลำดับ Merge (กัน conflict ในไฟล์นี้)
- migration ใหม่ = ไฟล์ใหม่เสมอ (ห้ามแก้ไฟล์ที่รันแล้ว) · **เจ้าของรันเองใน Supabase SQL Editor** จากลิงก์ `raw.githubusercontent.com/accountoei/oeiwealth/<branch>/supabase/migrations/<file>` → AI ตรวจด้วย SELECT ผ่าน connector (`execute_sql`): คอลัมน์ / ตาราง / ฟังก์ชัน `md5(replace(prosrc, E'\r', ''))` เทียบกับ DB ทดสอบในเครื่อง · RLS · สิทธิ์ anon · `get_advisors` → เจ้าของกด Merge · **รัน SQL ก่อนกด Merge เสมอ**
  - AI ห้ามเรียก `apply_migration` (ถูกยกเลิกทุกครั้ง) · migration ที่ลบ / เปลี่ยนชื่อ / แก้ข้อมูลเดิม ต้องถามเจ้าของก่อน
- ก่อน push: `service postgresql start; DB=fwv_test bash tests/run.sh --scenario` (ล่าสุด **576 checks** · นับจาก `grep -c "NOTICE:  PASS"`) + `npx tsc --noEmit && npx eslint src` + `next build` (env ปลอม) · ลบ `.next/types` หลัง build
- ดูหน้าจอโดยไม่ต้องมีฐานข้อมูล: หน้าชั่วคราว `src/app/login/zz-preview/page.tsx` (ข้อมูลสมมติ) + `next dev -p 3123` + Playwright (`/opt/npm-tools/node_modules/playwright/index.mjs`, `executablePath: /opt/pw-browsers/chromium`) แล้ว**ลบหน้าชั่วคราวก่อน commit**
- ทุก PR อัปเดตไฟล์นี้ (แถวการตัดสินใจ / รายการงาน / ประวัติ PR) และจำนวน checks ใน `AGENTS.md`
- ปิดงานด้วยภาษาไทย 3 ส่วน: เปลี่ยนอะไร · ต้องทำอะไร (SQL → Merge) · เช็กลิสต์ทดสอบด้วยข้อมูลสมมติ
- เจ้าของพิมพ์ "ถามก่อน (จะทำต่อ)" = **ตอบ / เสนอแนวทางอย่างเดียว ห้ามแก้โค้ด** จนกว่าจะบอก "ทำเลย / ok ทำได้เลย"
- ลิงก์ raw ของ branch ใช้ไม่ได้หลัง Merge (branch ถูกลบ) → ใช้ลิงก์ `.../main/...` แทน
- Edge Function: เจ้าของ deploy เองผ่าน Dashboard (Deploy a new function → Via Editor → วางโค้ดจาก raw link → Details → ปิด Verify JWT) · AI ตรวจด้วย `list_edge_functions` / `get_edge_function`
- GitHub Actions log ดาวน์โหลดจากที่นี่ไม่ได้ (blob host Forbidden) → ขอให้เจ้าของวาง log ขั้นที่ต้องดู · ดูสถานะได้ด้วย `gh api repos/.../actions/runs/<id>/jobs`
- ห้าม: ใส่ secret / ข้อมูลจริงใน repo · แตะ Vault key `fwv_bank_account_key` · ปิด RLS · กด Confirm Go-live ด้วยข้อมูลทดสอบ · ลบพอร์ต Citibank ตอนทดสอบ

## ยังไม่ได้ตัดสินใจ

- ตั้ง `SEC_API_KEY` (secopendata.sec.or.th) ถ้าจะดึง NAV กองทุน · (ทองคำ dry run อ่านราคาสมาคมฯ ได้แล้ว 21 ต.ค.)
- **มูลค่าตั้งต้นของอสังหาฯ:** ราคาซื้อ หรือ มูลค่าปัจจุบัน (แนะนำ: มูลค่าปัจจุบัน ใช้วิธีเดียวกันทุกรายการ เช่น ราคาประเมินราชการ) — ต้องตัดสินใจก่อนนำเข้าข้อมูลจริง
- ชื่อครอบครัวที่จะแสดงในระบบ (แก้เองได้ที่ Family → Members)
- **วัน Go-live ใหม่** (วิธีตั้งตกลงแล้ว = ปุ่มเปลี่ยนวัน) — แนะนำวันที่ 1 ของเดือนที่จะเริ่มใช้จริง
