# แผน: ผิดนัดชำระ · ดอกเบี้ยผิดนัด · ทบดอกค้างเข้าต้น (เงินให้กู้)

> สถานะ: **พักไว้ — รอแนวทาง** (คุยเมื่อ 10 ต.ค. 2569) · ยังไม่ได้เริ่มทำ
> ก่อนทำ: ให้ทนาย / นักบัญชียืนยันข้อกฎหมายด้านล่าง

## สิ่งที่เจ้าของระบบต้องการ
1. ดอกเบี้ยที่ทบต้น **ไม่นับเป็นทรัพย์สินใน Net Worth** — รับรู้เป็นรายได้ดอกเบี้ยเมื่อได้รับเงินจริงเท่านั้น
2. ผิดนัด **3 งวดติดต่อกัน** → ขึ้นให้คำนวณดอกเบี้ย / ทำตารางใหม่ และเปลี่ยนสถานะเป็น "มีความเสี่ยงไม่ได้คืน" อัตโนมัติ
3. ดอกเบี้ยผิดนัดระบุได้ **ไม่เกินที่กฎหมายกำหนด**
4. แสดงยอด "ดอกเบี้ยที่นำมาทบต้น" เฉพาะสัญญาสถานะ "มีความเสี่ยง"

## ข้อกฎหมายที่เกี่ยวข้อง (ต้องยืนยันก่อนทำ)
- เพดานดอกเบี้ยเงินกู้ระหว่างบุคคล: ไม่เกินร้อยละ 15 ต่อปี
- ป.พ.พ. ม.655: ห้ามคิดดอกเบี้ยในดอกเบี้ยค้าง — ทบเข้าต้นได้เมื่อดอกค้าง **ไม่น้อยกว่า 1 ปี** และ **ตกลงเป็นหนังสือ**
  → ขัดกับ "ทบต้นเมื่อผิดนัด 3 งวด" ข้อ 2
- ป.พ.พ. ม.224 / 224/1 (แก้ไขปี 2564): ดอกเบี้ยผิดนัดกรณีไม่ได้ตกลง ≈ ร้อยละ 5 ต่อปี (อัตราตามกฎหมาย + 2 · ปรับได้ตามพระราชกฤษฎีกา)
  และคิดจาก **เงินต้นของงวดที่ผิดนัด** เท่านั้น — ต้องตรวจอัตราปัจจุบัน

## แนวทางที่เสนอ (ยังไม่ตกลง)
- แยก 2 ขั้น
  - ผิดนัด 3 งวดติดกัน → สถานะ "มีความเสี่ยง" (งานตั้งเวลาตรวจทุกคืน) + เตือน + เริ่มคิดดอกเบี้ยผิดนัด + ทำตารางใหม่ได้ (ยังไม่ทบต้น)
  - ดอกค้าง ≥ 1 ปี → ปุ่ม "ทบดอกเข้าต้น" (ต้องติ๊กยืนยันมีข้อตกลงเป็นหนังสือ + แนบเอกสาร)
- เก็บ "ดอกเบี้ยทบต้น" เป็นยอดแยก ไม่รวมใน `loan_outstanding_at` / Net Worth
- รับชำระ: หักดอกงวดปัจจุบัน → ดอกทบต้น → เงินต้นเดิม · ส่วนดอก (รวมดอกทบต้น) = รายได้ ณ วันที่รับ
- เพดานอัตรา (ดอกเบี้ย / ดอกผิดนัด) เก็บในหน้าตั้งค่า (ADMIN) + บังคับในฐานข้อมูล

## คำถามที่ยังค้าง
- ก. ตกลงแยก 2 ขั้นข้างบนไหม
- ข. นับ "ผิดนัด" อย่างไร: งวดที่จ่ายบางส่วนนับไหม · ตารางรายปีใช้ "เลยกำหนด 90 วัน" แทน 3 งวดไหม
- ค. กลับมาจ่ายครบ → สถานะกลับ "ปกติ" เอง หรือ ADMIN เปลี่ยน
- ง. ข้อ 4: แสดงเมื่อสถานะมีความเสี่ยง **หรือ** ยังมีดอกทบต้นค้าง (กันยอดหายเมื่อสถานะกลับปกติ)
- จ. สัญญา "มีความเสี่ยง" ยังนับเงินต้นเต็มใน Net Worth ไหม (ตอนนี้: นับเต็ม · "ตัดหนี้สูญ" = 0)
