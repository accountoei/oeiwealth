## เปลี่ยนอะไร
- `src/app/(app)/income-expenses/page-data.ts` (ใหม่): แยกข้อมูลของหน้าเป็น 3 ชุด จำไว้แบบเดียวกับ Dashboard (ผู้ใช้แต่ละคนแยกกัน · ล้างทันทีเมื่อมีการบันทึก / งานเบื้องหลังเสร็จ · เพดาน 1 ชั่วโมง · วันใหม่ / deploy ใหม่ ถามใหม่)
  - `loadIeRef` ชุดไม่ขึ้นกับเดือน (~21 คำถาม): บัญชี · บัตร + ยอดบัตร · หนี้ · สมาชิก · อัตราแลกเปลี่ยน · วัน Go-live · หมวด + จำนวนที่ใช้ · คำเดาหมวด · รายการประจำ (รายได้ / ค่าใช้จ่าย / สาธารณูปโภค) · สัญญาเช่า + ทรัพย์สินของสัญญา · กรมธรรม์ / เคลมที่เปิดอยู่ · บ้าน / ที่ดิน · บัญชีเงินฝากในพอร์ต
  - `loadIeMonth(start, end)` ชุดของเดือน (~15 คำถาม): รายได้ · ค่าใช้จ่าย · เงินคืน · เงินเข้า–ออก + ชื่อทรัพย์สินในรายการ · งวดที่ครบกำหนด (อสังหาฯ / เงินให้กู้ / ประกัน / ค่าใช้จ่ายประจำ) · ยอดยกมา · ยอดอัปเดตคงเหลือ
  - `loadIePersonShares` ส่วนแบ่งรายได้ / ค่าใช้จ่ายของสมาชิกที่เลือก
  - เปลี่ยนเดือน / กลับเข้าหน้า ถามเฉพาะชุดที่ยังไม่ได้จำ · เดือนที่เคยเปิดแล้ว เปิดซ้ำไม่ต้องถาม Supabase จนกว่าจะมีการบันทึก
  - จำเฉพาะที่หน้าใช้: จำนวนรายการที่ใช้แต่ละหมวด + คำเดาหมวด คำนวณก่อนจำ (ไม่จำแถวดิบ)
  - ชื่อทรัพย์สินอื่นในรายการเงิน / ทรัพย์สินที่มีสัญญาเช่า ถามพร้อมรอบแรก (เดิมเป็นรอบที่ 2 หลังรอบแรกเสร็จ)
- `src/lib/data-cache.ts`: `cachedLoad` — จำผลของชุดคำถาม · มีคำถามที่ผิดพลาด → ไม่จำผลรอบนั้น (ใช้ผลที่ได้ตามเดิม แล้วถามใหม่ครั้งหน้า)
- `src/lib/pf-cash.ts`: บัญชีเงินฝากในพอร์ตอ่าน `investment_holdings` + พอร์ต + ทรัพย์สินพอร์ต ตรง คำถามเดียว · เดิมอ่าน `v_holdings_active` ซึ่งคำนวณมูลค่าทุกรายการไปด้วย (33 ms ไม่นับ RLS) แล้วถามชื่อพอร์ตอีกรอบ → 0.4 ms · รายการเท่าเดิม (ตรวจกับข้อมูลจริง 16 = 16) · หน้ารายละเอียดบัญชีธนาคาร / บัตรเครดิตเร็วขึ้นด้วย
- สถานะเงินคืน (`v_expense_reimbursement_status`): ดึงเฉพาะรายการของเดือนที่ดู (หน้าใช้แค่รายการในเดือน · เดิมดึงทุกเดือน)
- `AGENTS.md` §3: เพิ่มหน้า Income & Expenses ในรายการผลที่จำไว้ · คำถามใหม่ของหน้านี้ให้ใส่ใน `page-data.ts`
