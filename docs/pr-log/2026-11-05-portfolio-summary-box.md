## เปลี่ยนอะไร
- หน้าพอร์ต (`investments/[id]/page.tsx`, `NetInvestedBox.tsx`): กล่อง "มูลค่าเป็นบาท (ใช้ในความมั่งคั่งสุทธิ)" กับ "เงินลงทุนสุทธิ" รวมเป็นกล่องเดียว
  - หัวกล่อง = มูลค่าเป็นบาท (ตัวใหญ่) + มูลค่าสกุลพอร์ต · อัตรา + เงินโอนที่รอใส่ยอด (ถ้ามี) · ส่งเป็น children ให้ `NetInvestedBox`
  - บรรทัดต่อมา: เงินลงทุนสุทธิ (เงินโอนเข้า − โอนกลับ) · กำไร / ขาดทุนรวม · รายได้ลงทุนตั้งแต่ Go-live (ก่อนภาษี)
  - เอาออก: เงินฝากในพอร์ต, หลักทรัพย์ (มีตารางด้านล่างแล้ว), บรรทัด "มูลค่าล่าสุด" (ซ้ำหัวกล่อง), หมายเหตุ "เงินฝากคำนวณจาก Statement ล่าสุด…"
  - พอร์ตที่มียอดตั้งต้นก่อน Go-live (`OPENING_BALANCE`) แต่ยังไม่มี "เงินโอนก่อน Go-live" → ไม่แสดง % และตัวเลขกำไรเป็นสีเทา + ข้อความเตือน "ยังไม่ได้ใส่เงินโอนก่อน Go-live · กำไร / ขาดทุนยังไม่ครบ"
- หน้าแรก Investments (`investments/page.tsx`): กล่อง "จำนวนพอร์ต" รวมเข้ากล่อง "เงินฝากในพอร์ต (รวมเงินโอนรอใส่ยอด)" เป็นบรรทัดเล็ก "พอร์ตที่เปิด N พอร์ต · ปิดแล้ว M" → เหลือ 4 กล่องแถวเดียว (xl) เหมือนหน้าอื่น
