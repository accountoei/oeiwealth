# Private Business · มูลค่าตามงบการเงิน (กรอกกึ่งอัตโนมัติ) · ป้ายเส้นเฉลี่ย · หัวตาราง 2 บรรทัด

## What changed
- **แท็บอัปเดตมูลค่า** (หน้า Private Business):
  - คอลัมน์ใหม่ตามลำดับ: กิจการ · **เงินลงทุนรวม** · **มูลค่าตามงบการเงิน** · มูลค่าล่าสุด · มูลค่าใหม่ · เปลี่ยนแปลง (ไม่มีข้อมูล = "-")
  - มูลค่าตามงบการเงิน = ส่วนของผู้ถือหุ้นปีล่าสุดที่บันทึกในผลประกอบการ × % ที่ครอบครัวถือ
    - ส่วนของผู้ถือหุ้น = ทุนจดทะเบียน (หุ้นทั้งหมด × มูลค่าหุ้นที่ตราไว้) + กำไรสะสม (กำไรรวมทุกปี − ปันผลที่บริษัทจ่ายรวม)
    - ปีที่กรอก "ส่วนของผู้ถือหุ้น" เอง → ใช้ยอดที่กรอกแทน
    - ใต้ตัวเลขบอก "งบปี 25xx · ถือ x%"
  - ตัวช่วย **"กรอกตามงบการเงิน"** (ตำแหน่งเดียวกับ "ใส่ยอดทุกแถว"): เติมมูลค่าใหม่ทุกกิจการที่มีมูลค่าตามงบ + วิธีประเมิน = มูลค่าตามบัญชี · ตรวจ / แก้ได้ก่อนกด "บันทึก N รายการ" ณ วันที่ (≥ Go-live)
    - แถวที่ไม่ได้แก้ตัวเลข: หมายเหตุอัตโนมัติ "ตามงบการเงินปี 25xx · ทุน + กำไรสะสม × x%"
    - ล้างช่องที่กรอก / บันทึกแล้ว → วิธีประเมินกลับเป็น "ประมาณเอง"
  - วิธีประเมินในแถบบนเพิ่ม "มูลค่าตามบัญชี" (บันทึกทั้งชุดด้วยคำสั่งเดียว: ผิดแถวเดียว = ไม่บันทึกเลย · กติกาเดิมในฐานข้อมูล ปิดงวด / Go-live / สิทธิ์ ยังทำงาน)
- **กราฟผลประกอบการ**: ป้าย "เฉลี่ย 3 ปี" ย้ายไปมุมขวาบรรทัดเดียวกับ "รายได้ (บาท)" · กราฟกำไรยังมีเส้นประเหมือนเดิมแต่ไม่มีป้าย (ชี้ที่ปียังเห็นค่าในกล่องค่า)
- **ตารางผลประกอบการ** (หน้ากิจการ · แท็บกลุ่ม · บริษัทที่ปิดแล้ว): หัวตารางเหลือ 2 บรรทัด · ช่องปีเขียน "ปีบัญชี" + บรรทัดล่าง "หน่วย: ล้านบาท / บาท" ตามปุ่มหน่วย · "คน = รวมผู้บริหาร" ย้ายไปอยู่ใน ⓘ ของกล่อง
