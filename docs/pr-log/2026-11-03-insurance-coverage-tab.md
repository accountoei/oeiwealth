## เปลี่ยนอะไร
- หน้า Insurance: แท็บใหม่ "ความคุ้มครอง" ท้ายสุด (`insurance/CoverageTab.tsx`) ใช้ตัวกรองคนที่หัวหน้าเดิม
  - การ์ด: ทุนประกันชีวิต · IPD ต่อปี · ค่าห้องต่อวัน (ทั้งครอบครัว = สูงสุดรายคน) · โรคร้ายแรง · เบี้ยประกันสุขภาพต่อปี
  - ตารางแบ่งกลุ่ม สุขภาพ / ชีวิตและอุบัติเหตุ / โรคร้ายแรง / อื่น ๆ · ทั้งครอบครัว = ประเภท × คน (ย้ายตาราง "สิทธิ์คุ้มครองรายคน" ออกจากภาพรวม) · เลือกคน = แยกตามกรมธรรม์ + ใช้ปีนี้ / คงเหลือ / สิ้นสุด
  - กรมธรรม์ชีวิต / อุบัติเหตุที่ยังไม่ได้กรอกความคุ้มครองประเภทนั้น ใช้ทุนประกันของกรมธรรม์แทน (ป้าย "ทุนประกันของกรมธรรม์")
  - กล่อง "เรื่องที่ควรดู": กรมธรรม์สุขภาพที่ยังไม่กรอกความคุ้มครอง · ครบ / ต่ออายุใน 60 วัน · เบี้ยเลยกำหนด · วงเงินต่อปีใช้ ≥ 80% · คนที่ไม่มีประกันสุขภาพ / ทุนชีวิต
  - กล่อง "เคลมปี …" ของคนที่เลือก (ยอดยื่น / ได้รับ / สถานะ)
- หน้าพิมพ์ใหม่ `/print/insurance?p=` (A4 หน้าละคน · ใช้ PrintShell เดิม): ชื่อเต็ม วันเกิด อายุ · กรมธรรม์ที่มีผล (สุขภาพ → อุบัติเหตุ → ชีวิต) + ความคุ้มครอง / วงเงิน / หมายเหตุ · เว้นช่องเบอร์ Call Center
