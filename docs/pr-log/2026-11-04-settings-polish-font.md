## เปลี่ยนอะไร
- **เลือกแบบอักษรได้** (`src/lib/fonts.ts` · `src/components/FontPicker.tsx` · `HeaderActions.tsx` · `(app)/layout.tsx`):
  - เมนูผู้ใช้มุมขวาบนมีรายการ "การแสดงผล" อยู่บรรทัดก่อน "ออกจากระบบ" กดแล้วเปิด pop up ให้เลือก
  - มี 3 แบบ: IBM Plex Sans Thai (แบบเริ่มต้น) · Noto Sans Thai Looped (มีหัว ใกล้เคียง Tahoma) · Sarabun (มีหัว)
  - ทั้ง 3 แบบมีตัวเลขกว้างเท่ากัน และกว้างไม่เกินแบบเดิม
  - กดแล้วเปลี่ยนทั้งหน้าทันที และจำไว้ที่เครื่องนั้นด้วย cookie `fwv_font` (1 ปี)
  - ครั้งต่อไป Server สร้างหน้าด้วยแบบที่เลือกเลย หน้าจึงไม่กระพริบ
  - หน้าพิมพ์ (/print) ใช้แบบเริ่มต้นเสมอ
- **Opening Setup** (`settings/opening/`):
  - กล่องบนสุดรวมวัน Go-live, ตัวเลข ยังขาด / ควรตรวจ / พร้อม และปุ่ม [เปลี่ยนวัน Go-live] [Confirm Go-live] ไว้คู่กัน
  - Confirm เปิดเป็น pop up ถ้ายังมี "ยังขาด" จะบอกเหตุผลและไม่มีปุ่มยืนยัน
  - หลัง LIVE: ปุ่ม "ยกเลิก Go-live" อยู่ในกล่องสีเขียว ไม่มีปุ่มในแถวแท็บแล้ว
  - หมวดรวมอยู่ในกล่องเดียว แต่ละหมวดเป็นบรรทัดเดียวพร้อมจำนวน
    - หมวดที่มี "ยังขาด / ควรตรวจ" เปิดเองและแสดงเฉพาะแถวที่ต้องแก้ พร้อมลิงก์ "แสดงที่พร้อมแล้ว (N)"
    - หมวดที่พร้อมทั้งหมดยุบไว้
    - หลัง LIVE ยุบทุกหมวด
- **Month Closing** (`settings/month-closing/`):
  - สถานะของเดือนอยู่บนสุด: พร้อมปิด / ยังปิดไม่ได้เพราะ… / ยังไม่สิ้นเดือน / ปิดแล้ว (เวอร์ชัน · เวลาปิด · คำเตือนที่ปิดผ่าน)
  - เอาออก:
    - ลูกศรเลือกเดือน (หน้านี้เปิดที่เดือนที่ต้องปิดถัดไปเสมอ)
    - ปุ่ม "อัปเดตยอดคงเหลือ" (ใช้ลิงก์ "ไปแก้" ในแถว Cash & Bank ของ Checklist)
    - กล่อง "ความมั่งคั่งเปลี่ยนเพราะอะไร" และ "รายบุคคล" (ซ้ำกับ Dashboard)
  - ย้ายตารางบัตรเครดิต ณ สิ้นเดือน เข้าไปในแถว "Liabilities / บัตรเครดิต" ของ Checklist บรรทัดหัวแถวสรุปจำนวนบัตรและยอดรวม
  - กล่อง "เดือนที่ปิดแล้ว" อยู่ล่างสุด:
    - กดชื่อเดือนเพื่อดูรายละเอียดตอนปิด มีลิงก์ "← กลับไปเดือนที่ต้องปิด"
    - ปุ่ม "ยกเลิกการปิดเดือน <เดือนล่าสุด>" (ADMIN · เดิมชื่อ Reopen) อยู่หัวกล่อง เห็นทันทีหลังปิดเดือน
- **Settings โหลดเร็วขึ้น** (ไม่มี SQL · ผลลัพธ์เท่าเดิม):
  - Month Closing:
    - เดิมดึงข้อมูลต่อกัน 5 รอบ → ตอนนี้ดึงพร้อมกัน รอบที่สองมีเฉพาะส่วนที่ต้องรู้เดือนก่อน
    - ผลคำนวณที่หนัก (`month_closing_checks`, `month_net_worth_preview`, `bank_balances_at`) ใช้ `cachedRpc` เก็บไว้จนมีการบันทึก แบบเดียวกับ Dashboard
    - ไม่เรียก `month_investment_gain` แล้ว (ใช้แค่ในกล่องที่เอาออก)
  - FX & Prices: 2 รอบ → 1 รอบ (ราคาย้อนหลังดึงต่อจากรายการทันที)
  - User & Security: ส่วน Security (Audit Log / รายชื่อผู้ใช้) เริ่มดึงพร้อมข้อมูลผู้ใช้ ไม่รอหน้าเสร็จก่อน (`loadSecurity`)
