## เปลี่ยนอะไร
- **วันผ่อนผัน** (SQL): `loan_details.grace_days` (0–60 วัน · ค่าเริ่มต้น 0 = เหมือนเดิม)
  - `v_loan_schedule_status`: เลยวันครบกำหนดแต่ยังไม่เกินวันผ่อนผัน = `DUE` ("ครบกำหนด" สีเหลือง) · เกิน = `OVERDUE` · เพิ่มคอลัมน์ `grace_until` ท้ายวิว
  - ช่อง "ผ่อนผันหลังครบกำหนดงวด (วัน)" ในแก้ไขรายละเอียดสัญญา · แสดงในข้อมูลสัญญา
  - หน้าสัญญา: หัวตาราง "ครบกำหนด N งวด (ผ่อนผันถึง …)" · ปุ่มบันทึกรับชำระเติมงวดที่ครบกำหนดให้ด้วย
  - หน้ารายการเงินให้กู้ / แท็บรับชำระ / รายการรอรับในรายรับ-รายจ่าย: งวด `DUE` จากเดือนก่อนยังแสดง (ไม่ขึ้นแดง)
- **ข้อความยอดตั้งต้นไม่ตรงตาราง** แยกกรณี: น้อยกว่าตาราง = ผู้กู้คืนเงินต้นก่อนกำหนด (บอกวิธีใส่งวดที่คืนในตาราง) · มากกว่า = ผู้กู้ค้างชำระก่อน Go-live
- **ตารางผ่อน (`ScheduleGrid`)**
  - เปลี่ยนอัตราดอกเบี้ย / วิธีนับดอก → คิดดอกเบี้ยทุกงวดใหม่ทันที (เว้นงวดที่พิมพ์เอง · หน้าเพิ่มสัญญา: เฉพาะเมื่อแก้ตารางเองแล้ว)
  - แทรกงวดแล้วลงวันที่ระหว่างงวดปกติ (ห่างงวดถัดไปไม่ถึงเดือน) = งวดคืนเงินต้นเพิ่ม: ดอกเบี้ยถึงวันคืน "รวมในงวดถัดไป" (กด "แยก" เพื่อคิดแยก) · ตารางเดิมที่มีงวดแบบนี้ (ดอกเบี้ย 0) รู้จักให้เอง
  - เงินต้นรวมไม่เท่ายอด: ปุ่ม "หักจากงวดท้าย (จบเร็วขึ้น)" / "เพิ่มเข้างวดท้าย" และ "คำนวณค่างวดหลังงวดที่ N ใหม่ (จบวันเดิม)" (ค่างวดเท่ากัน → หาค่างวดใหม่ · ผ่อนเงินต้นไม่เท่ากัน → ลดตามสัดส่วน · ไม่แสดงสำหรับจ่ายแต่ดอกแล้วคืนก้อนท้าย)
  - ข้อความเตือนในตาราง (`data-warn`) ไม่นับเป็นข้อผิดพลาด → บันทึกสำเร็จแล้วหน้าต่างปิดเอง + แจ้งมุมขวาล่าง (`Modal.tsx`)
- `src/lib/loan-schedule.ts`: `recalcInterest` รองรับ `carry` · `isMidPeriod` · `annuityPrincipals` · `LOAN_SCHED_STATUS.DUE`
