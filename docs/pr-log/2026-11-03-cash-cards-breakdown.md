## เปลี่ยนอะไร
- หน้าบัญชีเงินฝาก แท็บภาพรวม: การ์ด "เงินเข้า / เงินออก / เงินเคลื่อนไหวสุทธิ" → "รายรับเข้าบัญชี / รายจ่ายจากบัญชี / รายการอื่นๆ"
  - แยกตาม `movement_type` ของ `cash_movements` เดือนที่เลือก (`src/app/(app)/financial/cash/flows.ts`): ยอดฝั่งบัญชีตรงกับ `private.bank_movement_effects` · โอนระหว่างบัญชีธนาคารของครอบครัวไม่นับ ยกเว้นค่าธรรมเนียมโอน
  - รายรับ = INCOME + REIMBURSEMENT_IN · รายจ่าย = EXPENSE / CARD_PAYMENT / LIABILITY_PAYMENT / ค่าธรรมเนียมโอน · อื่นๆ = ลงทุน / เงินกู้ / ซื้อขายทรัพย์สิน / เงินประกันการเช่า / แลกเงิน / อื่นๆ (แสดงเฉพาะบรรทัดที่มี)
  - รวม 3 การ์ด = เงินเข้า − เงินออกเดิม (ไม่นับโอนระหว่างบัญชี)
  - เอาลูกศร "จากเดือนก่อน" ออกจาก 3 การ์ดนี้ (การ์ดยอดเงินฝากรวมยังเทียบสิ้นเดือนก่อน)
- `src/lib/format.ts`: `money()` ยอดที่ปัดแล้วเป็นศูนย์แสดง "0.00" (ไม่ใช่ "-0.00") · ใหม่ `signedMoney` / `plusMoney` / `minusMoney` / `signedPct` / `isZero` (ศูนย์ → ไม่มี + / −) · `diffText` ด้วย
- เปลี่ยนจุดที่ต่อเครื่องหมาย "+" / "−" เองมาใช้ helper ข้างบน (~25 จุด): รายรับ–รายจ่าย (เงินเข้า–ออก), บัญชีเงินฝาก / บัญชีเงินสดในพอร์ต, ธุรกิจ, ปิดงวด, สมาชิก, บัตรเครดิต, Property, การลงทุน, Dashboard (% ในกราฟ / การ์ด), ราคารออนุมัติ
