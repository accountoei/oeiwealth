## เปลี่ยนอะไร
- ตารางเบี้ยและผลประโยชน์ในหน้ากรมธรรม์ (`[id]/FlowTable.tsx`)
  - คอลัมน์แรกเป็น **"ปีที่"** แทนป้าย เบี้ย / ผลประโยชน์ / เวนคืน = ปีกรมธรรม์ที่ครบรอบแล้ว ณ วันของแถว (`policyYearAt` ใน `src/lib/insurance-flow.ts`)
    - วันเริ่มสัญญา = ปีที่ 0 (เบี้ยงวดที่ 1) · ครบรอบปีที่ N = มูลค่าเวนคืนสิ้นปีที่ N ตามตารางในเล่ม + เบี้ยงวดที่ N + 1
    - รับเงินกลางปี = นับปีเต็มล่าสุด · ไม่มีวันเริ่มสัญญา = ช่องว่าง
    - แถวย่อย (จ่าย / รับ / ลงแล้ว) ยังมีป้ายในคอลัมน์แรกเหมือนเดิม
  - คอลัมน์ "รายการ" ย้ายไปท้ายตาราง (ก่อนปุ่ม) ชื่อใหม่ **"หมายเหตุ"** เหลือเฉพาะข้อมูลที่ไม่ซ้ำ: ชนิดผลประโยชน์ · ชื่อส่วน (สัญญาเพิ่มเติม) · หมายเหตุของงวด · "จ่ายจาก…" · ข้อความเงินก้อน · ตัดคำว่า "เบี้ยงวดที่ N" และ "สิ้นปีกรมธรรม์ที่ N" ออก
  - มูลค่าเวนคืนของปีก่อนปีแรกในตาราง (เช่น ตารางเริ่มปีที่ 2) แสดง 0.00 ตัวจาง (แสดงอย่างเดียว ไม่บันทึก)
- หน้ากรมธรรม์ (`[id]/page.tsx`): **สุทธิสะสม · จุดคุ้มทุน · สุทธิถึงวันนี้** นับเฉพาะสัญญาหลัก + สัญญาเพิ่มเติมแบบชีวิต / บำนาญ · ไม่นับเบี้ยสัญญาเพิ่มเติมสุขภาพ / อุบัติเหตุ (เบี้ยคุ้มครอง ไม่มีเงินคืน) · บอกไว้ใต้ยอด "ไม่นับเบี้ย…" และในบรรทัดตามตารางทั้งหมด · ลำดับแถวยังเรียงตามทั้งเล่ม · IRR "ทั้งเล่ม" ยังนับทุกส่วนเหมือนเดิม
- หน้าต่างแก้ตารางเบี้ย (`BookletScheduleEditor.tsx` ทั้งเล่ม · `InsScheduleEditor.tsx` ฉบับเดียว): ป้าย **"ก่อน Go-live"** ย้ายจากใต้ช่องวันที่ไปอยู่หน้าช่องหมายเหตุในบรรทัดเดียวกัน (แสดงอย่างเดียว ไม่บันทึก) · ตารางทั้งเล่มช่องหมายเหตุกว้างขึ้น ช่องยอดแต่ละส่วนแคบลงเล็กน้อย (iPad แนวนอน 3 ส่วนไม่ต้องเลื่อนข้าง) · ในหน้าต่างแก้ตารางยังใช้คำว่า "งวด"
