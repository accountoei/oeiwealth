## เปลี่ยนอะไร
- `property_deeds.salvage_value` (บาท) / `salvage_pct` (% ของต้นทุน) ใส่ได้อย่างใดอย่างหนึ่ง เฉพาะสิ่งปลูกสร้าง (constraint `pdeed_salvage_ck`) · `pdeed_component_ck` ให้อายุใช้งาน 0–100 (เดิม 1–100)
- `private.salvage_ok(jsonb)` ตรวจค่าราคาซาก · `save_property_components` และ `pay_property` (สิ่งปลูกสร้างแถวใหม่) บันทึกราคาซาก
- `v_property_cost_lots`: ค่าเสื่อม = (ยอด − ราคาซาก) × ปีที่ถือ ÷ อายุใช้งาน (ไม่เกินครบอายุ) · อายุ 0 ปี = ไม่หัก · ราคาซากเป็นบาท + ต้นทุนหลายก้อน (ซื้อมา + จ่ายต่อเติม) → แบ่งตามสัดส่วนต้นทุน · คอลัมน์ใหม่ต่อท้าย `component_id`, `salvage` (คอลัมน์เดิมเหมือนเดิม · `v_property_target_price` ใช้ค่าเสื่อมใหม่เอง)
- ตารางส่วนประกอบ (`ComponentTable.tsx`): ช่อง "ราคาซาก" หน้าช่องอายุใช้งาน พิมพ์ `10%` หรือ `100,000` (ออกจากช่องแล้วจัดรูปให้) · ตัวจาง "บาท หรือ %" · อายุใช้งานแถวใหม่เริ่มว่าง ตัวจาง "20" + บรรทัดจาง "ว่าง = 20 ปี · 0 = ไม่หักค่าเสื่อม"
- ฟอร์มจ่ายซื้อ / จ่ายเพิ่ม → "+ สิ่งปลูกสร้างใหม่" มีช่องราคาซาก + อายุใช้งานแบบเดียวกัน (`AssetTrade.tsx`, `asset-trade.ts`)
- `parseSalvage` ใน `src/lib/format.ts` (server action แปลงข้อความ → บาท / %) · `salvageText` / `lifeText` ใน `property/components.ts`
- หน้ารายละเอียด: "ราคาซาก 10% · อายุใช้งาน 20 ปี" / "ไม่หักค่าเสื่อม" · หน้าต่าง "ดูวิธีคิด" แสดงราคาซากของแต่ละก้อน
