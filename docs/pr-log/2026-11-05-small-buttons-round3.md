## เปลี่ยนอะไร
- ลบบรรทัด → ปุ่มเล็กสีแดง "ลบ": ส่วนประกอบทรัพย์สิน (รวม "ยืนยันลบ / ไม่"), ซื้อ/ขายทรัพย์สิน (เงินที่ได้รับ, ค่าใช้จ่าย, บรรทัดจ่าย), แยกมูลค่าทรัพย์สิน, ค่าใช้จ่ายทรัพย์สินหลายรายการ, ของในห้อง/มิเตอร์, ผู้รับผลประโยชน์, ผลตรวจสุขภาพ, แบ่งรายการรายรับรายจ่าย
- เพิ่มบรรทัด → ปุ่มเล็ก: "+ ที่ดิน (โฉนด)", "+ สิ่งปลูกสร้าง", "+ เพิ่มบรรทัด", "+ ค่าใช้จ่าย", "+ เงินที่ได้รับ", "+ เพิ่มแถว", "+ เพิ่มรายการ", "+ เพิ่มผู้รับผลประโยชน์", "+ เพิ่มงวดท้ายตาราง", "+ เพิ่มหมวดเอง"
- ตัวหนังสือที่เปิดฟอร์ม/สลับโหมด → ปุ่มเล็ก: "แก้ / + ตั้งตัดบัญชีอัตโนมัติ" (บัตรเครดิต), "ซ่อน" / "เปลี่ยนเลขบัญชี" (Bank Accounts), "ดู / แก้ทีละงวด" + "แสดงทุกงวด" (จ่ายเบี้ยประกัน), "เดือนนี้ไม่ได้รับ… / ไม่ได้จ่าย…", "เพิ่มรายการที่ตกหล่นก่อน Go-live (ADMIN)" ×6 หน้า, "แปลงเป็นจำนวนหน่วย" (หลักทรัพย์), "เลือกรูป / ลบรูป" (ครอบครัว), "ยกเลิก" ของ "เดือนนี้ไม่ได้จ่าย" (สีแดง), "ออกจากระบบ" หน้า MFA
- ปุ่มตอบ "ไม่ / ยกเลิก / ปิด / ไว้ทีหลัง" ข้างปุ่มยืนยัน → ปุ่มขอบเทา: หน้าต่างยืนยัน, ยืนยันลบ, ยืนยันยกเลิกการขาย, คำถามหลังรับชำระเงินกู้, CPI, เพิ่มอุปกรณ์ MFA, อัปโหลดเอกสารซ้ำ, ฟอร์มที่กางในหน้า
- แก้การโอนเงินพอร์ต: "ปิด" ใส่ `data-close` (ซ่อนในหน้าต่าง) · ประกัน "ข้าม / ปิด" → ปุ่มเล็ก "ข้าม"
