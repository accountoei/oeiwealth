## เปลี่ยนอะไร
- Investments: สัดส่วนตามประเภท / สกุลเงิน → มูลค่าลงทุนตามประเภท / สกุลเงิน
- Private Business: สัดส่วนมูลค่าธุรกิจของ… → มูลค่าธุรกิจตามกิจการ · มูลค่าตามสมาชิกครอบครัว → มูลค่าธุรกิจตามสมาชิกครอบครัว
- Loans Receivable: เงินต้นคงเหลือรวม → เงินให้กู้คงเหลือรวม · สรุปเงินต้นคงเหลือตามสถานะ → เงินให้กู้คงเหลือตามสถานะ
- Property: มูลค่าทรัพย์สินรวม (THB Equivalent) → มูลค่าอสังหาริมทรัพย์รวม (THB Equivalent) · ถึงวันนี้ · มูลค่าตามประเภท / การใช้งาน → มูลค่าอสังหาฯ ตามประเภท / ตามการใช้งาน
- Insurance: มูลค่าเวนคืนรวม (THB) → (THB Equivalent) · ถึงวันนี้ · ตามสมาชิกครอบครัว → มูลค่าเวนคืนตามสมาชิกครอบครัว
- Alternative: มูลค่าสินทรัพย์ทางเลือกรวม → มูลค่าสินทรัพย์อื่นรวม · สัดส่วนมูลค่าตามหมวด → มูลค่าสินทรัพย์อื่นตามหมวด · มูลค่าตามสมาชิกครอบครัว → มูลค่าสินทรัพย์อื่นตามสมาชิกครอบครัว
- Liabilities กล่องแรก: เดิมแสดงยอดแยกสกุล (หลายตัวเลข) → ยอดเดียวเป็นบาท (อัตราล่าสุด จาก v_fx_status) + รายการแยกตามสกุลเงินแบบกล่องยอดเงินฝากรวมของ Bank Accounts · ชื่อ "หนี้สินรวม (THB Equivalent) · ถึงวันนี้"
- Investments กล่อง "เงินฝากในพอร์ต": บรรทัด "x% ของมูลค่าลงทุนรวม" (ตัวหนา) + "รวมเงินโอนรอใส่ยอด y" (ถ้ามี) หรือ "อยู่ใน N พอร์ต"
