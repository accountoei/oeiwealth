   - หัวข้อตามประเภท (กด "แสดงทุกหัวข้อ" ดูที่เหลือ) · ช่อง: วงเงิน · สูงสุด (วัน / ครั้ง / งวด) · ณ วันที่ · หมายเหตุ

   - หัวข้อใหม่: สูญเสียอวัยวะ / ทุพพลภาพจากอุบัติเหตุ · ค่ารักษาจากอุบัติเหตุ · โรคร้ายแรงระยะเริ่มต้น–ปานกลาง (เดิม "โรคร้ายแรง" = ระยะรุนแรง) · ทุพพลภาพรายงวด · ความรับผิดส่วนแรก · ร่วมจ่าย (%) · ยกเว้นเบี้ย ("มีสิทธิ์" + ระบุส่วนที่ยกเว้นในหมายเหตุ)
   - ข้อมูลเดิมไม่ย้าย (ชื่อหัวข้อ "เสียชีวิต / ทุพพลภาพ จากอุบัติเหตุ" → "เสียชีวิตจากอุบัติเหตุ" · "โรคร้ายแรง" → "โรคร้ายแรงระยะรุนแรง")
