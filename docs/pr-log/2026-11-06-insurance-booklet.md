## ตกลงกับเจ้าของ (6 พ.ย. 2026 · "แบบ ข" → "ทำเลย")
1. **เก็บ 2 รายการเหมือนเดิม แต่แสดงเป็นเล่มเดียว**: สัญญาเพิ่มเติม (เช่น สุขภาพ / มะเร็ง) บันทึกเป็นอีกกรมธรรม์ที่ บริษัท + เลขกรมธรรม์เดียวกัน → IRR / ภาษี / งวดเบี้ย ยังแยกถูกตามรายการ
   - เล่มเดียวกัน = บริษัท (ไม่สนตัวพิมพ์ / ช่องว่างหัวท้าย) + เลขกรมธรรม์ (ไม่สนตัวพิมพ์ / ช่องว่าง) · ไม่มีเลขกรมธรรม์ = ไม่รวมเล่ม
   - รายการหลัก = ชีวิต → อุบัติเหตุ → สุขภาพ → ทรัพย์สิน (ประเภทเดียวกัน = ตามลำดับเดิม)
2. **ทุนประกัน vs ความคุ้มครอง**: ไม่คัดลอกตัวเลข · แท็บความคุ้มครองแสดงแถว "เสียชีวิต · ตามทุนประกัน" ให้เองเมื่อยังไม่มีแถวเสียชีวิต (กดแถว = บันทึกยอดจริง) · มีแถวจริงที่ยอดไม่เท่าทุน → แสดง "ทุนประกัน …" ตัวเล็กไว้เทียบ
3. **แท็บจ่ายเบี้ย**: 2 บรรทัดติดกัน + แถว "รวมทั้งเล่ม" (ยอดงวด / จ่ายแล้ว / คงเหลือ / ยอดที่กรอก) · กรอกพร้อมกันวัน / บัญชีเดียวกัน = ผูกเป็นชุดเดียว
4. **ตารางเบี้ยและผลประโยชน์ของสัญญาหลัก**: คอลัมน์ ชีวิต · สุขภาพ · รวมจ่าย (สัญญาเพิ่มเติมหลายฉบับ = คอลัมน์ "สัญญาเพิ่มเติม" ยอดรวม + ตัวเล็กแยกฉบับ) · งวดวันเดียวกันรวมแถวเดียว · กดยอดชีวิต / สุขภาพ = แก้งวดนั้น · สุทธิสะสมและจุดคุ้มทุนคิดจากเบี้ยทั้งเล่ม · IRR แสดง "ชีวิต" (เหมือนเดิม) + "ทั้งเล่ม" · ช่องรายการแคบลง (ความกว้างคงที่) · พอดีจอคอมและ iPad แนวนอน (เมนูยุบ)
5. **บัญชีธนาคาร / บัตรเครดิต / รายรับรายจ่าย**: จ่ายเบี้ยทั้งเล่มพร้อมกัน = แถวเดียวยอดรวม (เช่น 2,132.00) ตรงกับ Statement + บรรทัดเล็ก "ชีวิต 1,402.00 + สุขภาพ 730.00" · แก้ / ลบทีละส่วนที่หน้ากรมธรรม์ (ลิงก์ในแถว) · ภาษี / IRR / งวด ยังนับแยก
6. หน้าสัญญาเพิ่มเติมมีลิงก์ "ดูทั้งเล่ม (… · สัญญาหลัก)" · หน้าสัญญาหลักมี "ในเล่มนี้" (ทุน · เบี้ยต่อปีของแต่ละส่วน + รวมเบี้ยทั้งเล่ม)
