# Bank Accounts: คำอธิบายย้ายเข้ากล่อง + ปุ่ม "แสดงเลขเต็ม" ไม่ปิดหน้าต่างเอง

- วันที่: 5 พ.ย. 2026 · branch `fix/cash-notes-reveal`
- SQL: ไม่มี SQL
- ทดสอบ: tsc / eslint (0 errors) / build ผ่าน · จำลองหน้าต่าง "แก้ไขรายละเอียด" ในเครื่อง (Playwright + Supabase จำลอง): กด "แสดงเลขเต็ม" → หน้าต่างยังเปิดและเห็นเลข · กด "บันทึกข้อมูลบัญชี" → หน้าต่างปิดเองตามเดิม

## เปลี่ยนอะไร
- หน้า Bank Accounts: เอาบรรทัดคำอธิบายใต้กล่องสรุปออก แล้วย้ายเข้าไปในกล่อง
  - ยอดเงินฝากรวม: "ยอดสกุลอื่นแปลงเป็นบาทด้วยอัตราล่าสุด"
  - รายการอื่นๆ: "ไม่นับเงินโอนระหว่างบัญชีของครอบครัวเอง (ค่าธรรมเนียมโอนอยู่ในรายจ่าย) · เงินออกแสดงเป็นยอดติดลบ" (`FlowCard` prop `note`)
- แก้บั๊ก: กด "แสดงเลขเต็ม" ในหน้าต่าง "แก้ไขรายละเอียด" ของบัญชีแล้วหน้าต่างปิดเอง ไม่เห็นเลข (เลขถอดรหัสได้ปกติ · Audit Log มีบันทึก)
  - สาเหตุ: `Modal` ปิดเองหลังกดส่งฟอร์มเมื่อเห็นข้อความสีเขียว · ส่วนเจ้าของบัญชี (`OwnershipEditor`) แสดง "รวม 100%" สีเขียวค้างไว้ → ถูกนับเป็น "บันทึกสำเร็จ"
  - `Modal.tsx`: ฟอร์มที่มี `data-no-close` ไม่ทำให้หน้าต่างปิดเอง · ข้อความสีเขียวที่มี `data-info` ไม่นับเป็นข้อความบันทึกสำเร็จ
  - ฟอร์ม "แสดงเลขเต็ม" ใส่ `data-no-close` · "รวม 100%" ใส่ `data-info`

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| คำอธิบาย "เงินออกแสดงเป็นยอดติดลบ" | อยู่ในกล่องรายการอื่นๆ (มีทั้งเข้าและออก) · กล่องรายจ่ายไม่ต้องมี (ออกอย่างเดียว) |
| ข้อความสีเขียวแบบแสดงค้าง ในหน้าต่าง pop up | ใส่ `data-info` ทุกครั้ง ไม่งั้นหน้าต่างปิดเองเมื่อกดปุ่มอื่น |
