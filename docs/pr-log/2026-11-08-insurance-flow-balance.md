## เปลี่ยนอะไร
- ตารางเบี้ยและผลประโยชน์ในหน้ากรมธรรม์ (`[id]/FlowTable.tsx`)
  - ป้าย **เวนคืนคุ้มทุน / คุ้มทุน** อยู่ข้างป้ายสถานะในบรรทัดเดียว · ไม่มีคำว่า "คาดการณ์" ใต้ป้ายแล้ว (สุทธิสะสมตัวจาง + กล่องจุดคุ้มทุนบอกอยู่แล้ว)
  - **ความกว้างคอลัมน์**: ทุกช่องกว้างคงที่ (px) = กว้างขั้นต่ำ · จอกว้างกว่านี้ ส่วนที่เหลือแบ่งให้ทุกช่องตามสัดส่วน (เดิมช่องหมายเหตุรับไปทั้งหมด ด้านขวาโล่ง) · เล่ม 2 ส่วน + อายุ + สุทธิสะสม + มูลค่าเวนคืน = 1,024 px พอดี iPad แนวนอน
  - ไม่มีคอลัมน์ปุ่มแยก: ปุ่มของแถว (บันทึกจ่าย / บันทึกรับ / ยกเลิกทั้งก้อน) อยู่ในช่องหมายเหตุชิดขวา (ข้อความยาว = ปุ่มลงบรรทัดถัดไป) · เดิมปุ่ม "ยกเลิกทั้งก้อน" / ปุ่มคู่ล้นคอลัมน์ทำให้ตารางเลื่อนข้าง · ช่องสุดท้ายแคบ 16 px = เครื่องหมาย › ของแถวที่กดแก้ได้
  - ช่องสถานะกว้างขึ้น (120 px) ให้ "รอ" + "เวนคืนคุ้มทุน" อยู่บรรทัดเดียว
- หน้ากรมธรรม์ (`[id]/page.tsx`): **งวดเบี้ยกับงวดผลประโยชน์ที่ครบวันเดียวกัน = แถวเดียว**
  - ยอดอยู่คนละคอลัมน์ (จ่ายเบี้ย / รับผลประโยชน์) · ป้ายสถานะ 2 อันบอกฝั่ง: รอจ่าย · รอรับ / ค้างจ่าย · ค้างรับ / จ่ายบางส่วน · รับบางส่วน (จ่ายแล้ว · รับแล้ว · ก่อน Go-live เหมือนเดิม · ข้อความซ้ำแสดงอันเดียว)
  - แก้งวด = กดยอดของงวดนั้น (เส้นประใต้ยอด) แทนกดแถว เพราะแถวเดียวมี 2 งวด
  - สุทธิสะสมของแถว = หลังรับ (วันเดียวกันนับจ่ายก่อนรับ) · หมายเหตุ / เงินจริง (แถวย่อย) ของทั้งสองงวดรวมกัน
  - วันละ 1 งวดผลประโยชน์ · วันอื่นในปีเดียวกันยังแยกแถว (ปีที่เดียวกัน) · ตัวกรอง "ผลประโยชน์" นับแถวที่รวมด้วย
  - เล่มที่มีสัญญาเพิ่มเติมรวมกับแถวเบี้ยทั้งเล่มของวันนั้น
