## เปลี่ยนอะไร
- **ปุ่มกระดิ่ง To-Do List** ขวาบน (`src/components/HeaderActions.tsx`): ตัวเลขงานค้างแบบเดิม (แดง = มีเรื่องด่วน · เหลือง = รอทำ) · ชี้เมาส์ = "To-Do List · ค้าง X รายการ (ด่วน Y)" · กด = ไปหน้า To-Do List · อยู่หน้า To-Do = ปุ่มเป็นสีฟ้า
- **ปุ่มผู้ใช้** (วงกลมชื่อย่อ + ▾): ชี้ = เห็นชื่อ · กด / แตะ = เมนู ชื่อ · อีเมล · สิทธิ์ · ออกจากระบบ · ปิดเมื่อกดที่อื่น / Esc / เปลี่ยนหน้า · ใช้แป้นพิมพ์ได้ (Enter / ↓ เปิด, Esc ปิด)
- **แถบซ้าย** (`Sidebar.tsx`): เอาเมนู To-Do List และกล่องผู้ใช้ / ออกจากระบบด้านล่างออก · `nav.ts` เพิ่ม `sidebar: false` (ยังเป็นชื่อหน้า "To-Do List" ที่แถบบน และค้นหาได้)
- **แถบบน** (`src/components/AppHeader.tsx` แยกจาก `layout.tsx`):
  - ช่องชื่อเมนูกว้างคงที่ 13.5rem (พอดีชื่อยาวสุด Cash & Bank Accounts + ⓘ) → ช่องค้นหาเริ่มที่เดิมทุกหน้า
  - ความกว้างช่องค้นหาคิดจากความกว้างแถบบนอย่างเดียว (ไม่ขึ้นกับตัวเลือกของหน้า) → ขอบขวาก็ที่เดิม
  - แถบบนกว้าง ≥ 936px (จอ 1280 ที่แถบซ้ายกว้างปกติ รวมแถบเลื่อน Windows) = แถวเดียว · แคบกว่า = คน / เดือนขึ้นบรรทัดที่สอง ชิดขวา
  - ใช้ `@container` ของแถบบน (ไม่ใช่ขนาดจอ) → ยุบ / ยืดแถบซ้ายแล้วจัดใหม่ถูกเอง
- **มือถือ**: ช่องค้นหาเป็นปุ่มแว่นขยายข้างกระดิ่ง · แตะแล้วช่องค้นหาเต็มแถวบน + แป้นพิมพ์ขึ้นทันที · "ยกเลิก" = ปิด · คน + เดือนอยู่บรรทัดเดียวที่จอ ~390px (ช่องเลือกแคบลงเล็กน้อยเฉพาะมือถือ) · แถบบนสูงเท่าเดิม (2 แถว)
