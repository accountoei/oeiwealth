## เปลี่ยนอะไร
- **ⓘ ข้อความล้นกล่อง** (`src/components/HeaderBar.tsx` · `InfoTip`): กล่องคำอธิบายตั้ง `whitespace-normal` + `text-left` เอง ไม่รับค่าจากที่วาง · เดิมหัวคอลัมน์ "ปีที่" (#387) ตั้งไม่ตัดบรรทัด → ข้อความยาวบรรทัดเดียวล้นกล่องทับตาราง · แก้ทุกหน้าที่ใช้ ⓘ
- ตารางเบี้ยและผลประโยชน์ (`[id]/FlowTable.tsx`)
  - คอลัมน์ใหม่ต่อจากปีที่: **อายุ** (อายุเต็มปีของผู้เอาประกัน ณ วันที่ของแถว จากวันเกิดในหน้า Family · ไม่มีวันเกิด = ไม่แสดงคอลัมน์) และ **งวดที่** (งวดเบี้ยของสัญญาหลัก · วันที่มีแต่สัญญาเพิ่มเติม = งวดของส่วนแรก · แถวผลประโยชน์ / มูลค่าเวนคืน = ว่าง)
  - หัวคอลัมน์วันที่ → **"วันที่ครบกำหนด"**
  - แถวย่อย (จ่าย / รับ / ลงแล้ว): ป้ายคร่อม 3 ช่องแรก · ข้อความ "จ่ายจาก…" ใช้ช่องว่างตั้งแต่สุทธิสะสมถึงหมายเหตุ (บรรทัดเดียว)
  - ช่องอื่นแคบลงเล็กน้อย ช่องหมายเหตุรับพื้นที่ที่เหลือ · เล่ม 2 ส่วน + มูลค่าเวนคืน กว้างขั้นต่ำ 64rem (พอดี iPad แนวนอน)
  - ป้ายใหม่ **"เวนคืนคุ้มทุน"** (สีฟ้า) · "คาดการณ์" เป็นตัวเล็กข้างป้ายแทนในวงเล็บ
- หน้ากรมธรรม์ (`[id]/page.tsx`)
  - เวนคืนคุ้มทุน (`cvBreakEven` ใน `src/lib/insurance-flow.ts`) = ปีแรกที่มูลค่าเวนคืนตามสัญญา ≥ เบี้ยสุทธิที่จ่ายไปก่อนวันนั้น (เฉพาะส่วนที่นับในสุทธิสะสม · ไม่นับรายการวันเดียวกัน เพราะเวนคืนวันครบรอบไม่ต้องจ่ายเบี้ยงวดนั้น · คุ้มทุนแล้วโดยไม่ต้องเวนคืน = ไม่ติด)
  - กล่องจุดคุ้มทุน: มีตารางมูลค่าเวนคืน = 2 บรรทัด **ถ้าเวนคืน** (ปีที่ · วันที่) / **ถ้าไม่เวนคืน** (เดิม)
  - แถวที่มีแต่สัญญาเพิ่มเติมแบบสุขภาพ และแถวมูลค่าเวนคืนอย่างเดียว แสดงสุทธิสะสมยกมา (เดิมว่าง) → เทียบกับมูลค่าเวนคืนได้ทุกแถว
  - อ่าน `persons.birth_date` ของผู้เอาประกันเพิ่มใน query เดิม (ไม่มี query เพิ่ม)
