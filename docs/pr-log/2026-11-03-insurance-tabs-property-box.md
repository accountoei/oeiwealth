## เปลี่ยนอะไร
- **หน้า Insurance**: ลำดับแท็บ ภาพรวม · ความคุ้มครอง · อัปเดตมูลค่าเวนคืน · บันทึกรับผลประโยชน์ · จ่ายชำระเบี้ยประกัน (ความคุ้มครองย้ายจากท้ายสุดมาต่อภาพรวม)
- **ภาพรวม → ตารางกรมธรรม์**: ตัวกรอง "ประเภท" กับ "สถานะ" เป็น dropdown แถวบนแบบหน้าทรัพย์สิน (`src/components/UrlSelect.tsx` · ?t= / ?s=) · สถานะตั้งต้น = มีผล (เลือก "ทั้งหมด" เพื่อดูฉบับที่สิ้นสุดแล้ว) · ยอดรวม "รวม n ฉบับ · เบี้ย …/ปี · มูลค่าเวนคืน …" ตามตัวกรองอยู่ชิดขวาแถวบน · เอาแถวรวมท้ายตารางออก
- **หน้ากรมธรรม์แต่ละฉบับ** (`insurance/[id]`): ส่วนบน (มูลค่าเวนคืน · เอกสาร · รายละเอียด) เหมือนเดิม · ด้านล่างเป็นแท็บ ความคุ้มครอง (+ กล่องเคลม · ปุ่มบันทึกเคลมย้ายมาอยู่ในกล่องนี้) · มูลค่าเวนคืน (ประวัติมูลค่า + ตารางตามสัญญา แสดงในแท็บเลย · ปุ่ม pop up ในกล่องด้านบนยังอยู่) · รับผลประโยชน์ · ชำระเบี้ย · เปิดที่ความคุ้มครองเสมอ (?tab= เปิดแท็บอื่นได้) · ประกันทรัพย์สินไม่มีแท็บรับผลประโยชน์ และมีแท็บมูลค่าเวนคืนเฉพาะที่มีมูลค่าเวนคืน · ชื่อทรัพย์สินที่คุ้มครองกดไปหน้าทรัพย์สินได้
- **หน้าทรัพย์สินแต่ละรายการ** (`property/[id]`): กล่อง "ประกันของทรัพย์สินนี้" ใต้กล่องมูลค่า กรมธรรม์ละบรรทัด (บริษัท · เลขกรมธรรม์ · ทุน · เบี้ย/ปี · ถึงวันที่ · ใกล้ครบ / เบี้ยเลยกำหนด / เบี้ยงวดถัดไป) กดไปหน้ากรมธรรม์ · ยังไม่มี = ปุ่ม "+ เพิ่มประกันทรัพย์สินนี้" → `/insurance/new?type=PROPERTY&asset=<id>` (เลือกประเภทและทรัพย์สินไว้ให้)
- **เบี้ยประกันทรัพย์สิน = ค่าใช้จ่ายของทรัพย์สิน**: จ่ายเบี้ย (แท็บจ่ายชำระเบี้ย / หน้ากรมธรรม์) ของกรมธรรม์ประเภทประกันทรัพย์สินที่ระบุทรัพย์สิน → ผูก `related_asset_id` = ทรัพย์สินนั้น (ผ่าน `add_expense` เดิม) · หน้าทรัพย์สินแสดงในกล่องค่าใช้จ่าย หัวข้อ "เบี้ยประกัน" (แก้ / ลบที่หน้ากรมธรรม์) · รวมใน "ค่าใช้จ่าย … บาท" ของกล่องมูลค่า · เบี้ยต่อปีของกรมธรรม์ที่มีผลรวมใน "ประมาณการต่อปี" · หน้า Property แท็บค่าใช้จ่าย / การ์ดรายได้สุทธิ และราคาขายขั้นต่ำที่คุ้มนับด้วย (ใช้ related_asset_id อยู่แล้ว) · Income & Expenses ยังเป็นรายการเดียว ไม่นับซ้ำ
  - ภาษี: ค่าใช้จ่ายที่ผูกทรัพย์สินหมวดอสังหาฯ นับในค่าใช้จ่ายจริงของทรัพย์สินในแบบคำนวณภาษี (เหมือนค่าใช้จ่ายทรัพย์สินอื่น)
  - ข้อมูลเดิม: ในระบบยังไม่มีกรมธรรม์ประกันทรัพย์สิน จึงไม่ต้องย้อนแก้รายการเก่า

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| กล่องประกันในหน้าทรัพย์สิน | แสดงข้อมูลเลย (ไม่ใช่ pop up) + ลิงก์ไปกรมธรรม์ · ยังไม่มี = ปุ่มเพิ่ม เลือกประเภท / ทรัพย์สินไว้ให้ (เจ้าของ 3 พ.ย. 2026) |
| เบี้ยประกันทรัพย์สิน | นับเป็นค่าใช้จ่ายของทรัพย์สินนั้น (เจ้าของ 3 พ.ย. 2026) |
| แท็บหน้ากรมธรรม์ | ความคุ้มครอง (+ เคลม) · มูลค่าเวนคืน · รับผลประโยชน์ · ชำระเบี้ย · เปิดที่ความคุ้มครอง (เจ้าของ 3 พ.ย. 2026) |
| แท็บหน้า Insurance | ความคุ้มครองต่อจากภาพรวม (เจ้าของ 3 พ.ย. 2026 · แทนที่ "ไว้ท้ายสุด") |
| ตัวกรองภาพรวม | ประเภท + สถานะ (ตั้งต้น มีผล) และยอดรวมอยู่ด้านบนแบบหน้าทรัพย์สิน (เจ้าของ 3 พ.ย. 2026) |
| ประกันชีวิตพ่วงสุขภาพ | บันทึก 2 รายการเลขกรมธรรม์เดียวกัน (ชีวิต + สุขภาพ) เพราะลดหย่อนภาษีแยกตามประเภท (ตอบเจ้าของ 3 พ.ย. 2026 · ไม่ต้องแก้โค้ด) |
