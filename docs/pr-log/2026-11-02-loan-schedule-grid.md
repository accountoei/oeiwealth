## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| คำนวณดอกเบี้ยใหม่ | ทันทีทุกครั้งที่แก้ (ไม่ต้องกดปุ่ม) · ดอกเบี้ยที่พิมพ์เองไม่ถูกทับ |
| ยอดตั้งต้น | = เงินต้นตามสัญญา − เงินต้นของงวดที่ครบกำหนดถึงวันตั้งต้น · ระบบเติมให้ แก้ทับได้ (ใส่มากกว่า = งวดก่อน Go-live ที่ยังไม่ได้รับขึ้น "เลยกำหนด") |
| วันตั้งต้น | ไม่ให้แก้รายสัญญา (= วันก่อน Go-live ทุกรายการ) · เปลี่ยนด้วยการเลื่อนวัน Go-live |
| แก้เงินต้น / ยอดตั้งต้น | เฉพาะสัญญาที่ให้กู้ก่อน Go-live · ระบบ LIVE แล้ว ฐานข้อมูลบังคับ ADMIN + หมายเหตุ (เดิม) |
