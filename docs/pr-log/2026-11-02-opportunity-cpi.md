## เปลี่ยนอะไร
- ตารางใหม่ `cpi_annual`: ดัชนีราคาผู้บริโภคไทย ค่าเฉลี่ยทั้งปี มีข้อมูลตั้งต้น พ.ศ. 2503–2568 จาก World Bank `FP.CPI.TOTL` (2010 = 100) ซึ่งมาจากตัวเลขของ สนค.
  - RLS: ทุก Role อ่านได้ · ADMIN เพิ่ม / แก้ได้ (แบบ `fx_rates`)
  - RPC `set_cpi_year`: ADMIN เพิ่มปีถัดไปหรือแก้ปีล่าสุด จาก % เงินเฟ้อทั้งปี โดยดัชนี = ปีก่อน × (1 + %) และใส่ได้เฉพาะปีที่จบแล้ว
  - RPC `delete_cpi_year`: ลบได้เฉพาะปีล่าสุด
- `families.opportunity_method` (`FIXED` / `CPI_PLUS`, ค่าเริ่มต้น `FIXED` เหมือนเดิม) และ `property_details.opportunity_method` (ว่าง = ใช้ของครอบครัว)
  - แปลงที่ตั้งอัตราเองไว้ก่อนหน้า (ยังไม่ได้เลือกวิธี) = อัตราคงที่
- `v_property_cost_lots`: ดอกเบี้ยคิดตามวิธีที่เลือก และเพิ่มคอลัมน์ `method`, `cpi_factor`, `cpi_to_year` ต่อท้าย
  - CPI_PLUS = ยอด × (CPI ปีล่าสุด ÷ CPI ปีที่จ่าย × (1 + ส่วนเพิ่ม)^ปี − 1)
  - ก้อนที่จ่ายหลังปีล่าสุดที่มีดัชนี ใช้ตัวคูณเงินเฟ้อ = 1
- `v_property_target_price`: เพิ่มคอลัมน์ `method`, `cpi_from_year`, `cpi_to_year`, `cpi_avg_pct` (เงินเฟ้อเฉลี่ยช่วงที่ถือ) ต่อท้าย
- หน้าจอ:
  - Settings › FX & Prices: เลือกวิธีคิด (เปลี่ยนวิธีแล้วต้องกรอกตัวเลขใหม่ · ป้ายเปลี่ยนเป็น "ส่วนเพิ่มเหนือเงินเฟ้อ" แนะนำ 2%) และตารางเงินเฟ้อรายปี (10 ปีล่าสุด + ดูย้อนหลัง) พร้อมฟอร์ม ADMIN
  - Property › แก้ไขข้อมูล: เลือก ใช้ของครอบครัว / อัตราคงที่ / เงินเฟ้อ + ส่วนเพิ่ม
  - กล่องราคาขายขั้นต่ำ: บอกวิธีที่ใช้ เช่น "ของครอบครัว: เงินเฟ้อ + 2%" และเมื่อเป็นอัตราคงที่ แสดงข้อความสีเทา "เงินเฟ้อช่วงที่ถือ (ปี–ปี) เฉลี่ย x.xx% ต่อปี"
  - หน้าต่าง "ดูวิธีคิด" แสดงตัวคูณเงินเฟ้อรายก้อน

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| รูปแบบ | ราคาขายขั้นต่ำยังเป็นตัวเลขเดียว · เลือกวิธีคิดได้ 2 แบบ (แนวทาง ก) + ข้อความเทียบเงินเฟ้อสีเทาตอนใช้อัตราคงที่ (จากแนวทาง ข) |
| ช่องตัวเลขเดิม | ใช้ช่องเดิม: อัตราคงที่ = อัตราเต็ม · เงินเฟ้อ + ส่วนเพิ่ม = ส่วนเพิ่ม (แนะนำ 2%) · เปลี่ยนวิธีต้องกรอกใหม่ |
| รายแปลง | เลือกได้เฉพาะปุ่ม "แก้ไขข้อมูล" (ไม่มีในฟอร์มเพิ่มทรัพย์สิน) |
| ข้อมูลเงินเฟ้อ | ค่าเฉลี่ยทั้งปี · ใช้ถึงปีล่าสุดที่มีข้อมูลครบทั้งปี (ไม่ใช้บางเดือน) · ปีต่อไป ADMIN กรอก % ที่ สนค. ประกาศ |
| ค่าเสื่อม / ค่าเช่า | คิดเหมือนเดิม: หักค่าเสื่อม · ค่าเช่าแสดงประกอบเท่านั้น (ไม่หัก) |
| ค่าของครอบครัว | migration ไม่เปลี่ยนค่าที่มีอยู่ (ยังเป็นอัตราคงที่) · เจ้าของเปลี่ยนเองที่ Settings |
