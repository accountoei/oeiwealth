## เปลี่ยนอะไร
- **ปุ่ม "ยกเลิก" (ผลประโยชน์ที่รับแล้ว)**: `InsuranceBatch.tsx` เดิมฟอร์มบันทึกครอบทั้งตาราง ส่วนปุ่มยกเลิก (`UndoButton`) เป็นฟอร์มของตัวเองซ้อนอยู่ข้างใน · เบราว์เซอร์ไม่รองรับฟอร์มซ้อนฟอร์ม กดแล้วจึงไม่เกิดอะไรขึ้น → ตอนนี้ฟอร์มบันทึกครอบเฉพาะปุ่มบันทึกด้านล่าง
  - ตรวจตารางบันทึกรับ / จ่ายหน้าอื่นแล้ว ไม่มีปุ่มที่เป็นฟอร์มซ้อนอยู่ในตารางแบบนี้ (ที่อื่นเปิดเป็นหน้าต่าง pop up)
- **แท็บค่าใช้จ่าย Property = ตารางเดียว** (`ExpenseBatch.tsx` · เดิม 3 กล่อง: ค่าใช้จ่ายประจำ / ค่าใช้จ่ายอื่น / ค่าใช้จ่ายที่บันทึกแล้ว)
  - ค่าใช้จ่ายประจำ (งวดเดือนนี้ + ค้างจ่ายยกมา) → บรรทัดคั่น "ค่าใช้จ่ายอื่นของทรัพย์สิน" + แถวกรอก (ทรัพย์สิน · ประเภท + รายการ · ยอด · จ่ายจาก · ลบ) + ปุ่ม "+ เพิ่มแถว"
  - รายการอื่นที่จ่ายแล้วในเดือนนี้ต่อท้าย (กดยอดแก้ / ลบได้เหมือนเดิม) · ค่าใช้จ่ายประจำที่จ่ายแล้วอยู่ในแถวของงวดนั้น
  - บรรทัดสุดท้าย "จ่ายเดือนนี้รวม (ตามวันที่จ่าย)" = ตัวเลขเดียวกับการ์ดภาพรวม
  - ฟอร์มบันทึกครอบเฉพาะปุ่มบันทึก (แบบเดียวกับข้อแรก) · กล่องภาษีที่ดินแยกไว้เหมือนเดิม

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| แท็บค่าใช้จ่าย Property | ตารางเดียว: ประจำ + ค่าใช้จ่ายอื่น (กรอก) + ที่จ่ายแล้วเดือนนี้ + ยอดรวม · กล่องภาษีที่ดินแยก |
| ฟอร์มบันทึกหลายรายการ | ครอบเฉพาะปุ่มบันทึก ไม่ครอบตาราง (กันฟอร์มซ้อนฟอร์ม) |
