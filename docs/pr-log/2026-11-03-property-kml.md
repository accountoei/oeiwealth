## เปลี่ยนอะไร
- `src/lib/kml.ts`: สร้างไฟล์ KML
  - แยกโฟลเดอร์ตามกลุ่มทำเล
  - สีหมุดตามการใช้งาน
  - มี ExtendedData (กลุ่มทำเล / ประเภท / การใช้งาน) ให้ My Maps "จัดกลุ่มตาม" ได้
  - ไม่ใส่มูลค่าหรือราคา เพราะไฟล์อาจถูกส่งต่อ
- `PropertyTable.tsx`: ปุ่ม "ส่งออกแผนที่ (KML)" ใต้ตัวกรอง
  - ส่งออกเฉพาะแปลงตามตัวกรองที่มีพิกัด และบอกจำนวนแปลงที่ยังไม่มีพิกัด
  - สร้างไฟล์ในเบราว์เซอร์ ไม่ผ่าน server
- `property/page.tsx`: ดึง `latitude`, `longitude`, `address` เพิ่ม
