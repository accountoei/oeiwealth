# บันทึกรายการ PR (หนึ่งไฟล์ต่อหนึ่ง PR) · เลิกใช้แล้ว

> ⛔ **ตั้งแต่ 10 พ.ย. 2026 ไม่สร้างไฟล์ใหม่ในโฟลเดอร์นี้แล้ว** · บันทึกของแต่ละ PR เขียนในคำอธิบาย PR บน GitHub แทน (ไฟล์ซ้ำกับคำอธิบาย PR และเพิ่มขั้นตอนทุก PR) · ไฟล์เดิม (#283 ถึง 10 พ.ย. 2026) เก็บไว้อ้างอิง · ด้านล่างคือกติกาเดิม

> ตั้งแต่ 2 พ.ย. 2026 · **ทุก PR สร้างไฟล์บันทึกของตัวเองในโฟลเดอร์นี้** แทนการเพิ่มแถวในตาราง "ประวัติการปรับปรุง" / "การตัดสินใจที่ตกลงแล้ว" ของ `docs/PRE_LAUNCH_CHECKLIST.md`
> เหตุผล: เดิมทุก PR เพิ่มแถวท้ายตารางเดียวกัน → PR ที่เปิดพร้อมกันชนกัน (merge conflict) ทุกครั้งที่มีตัวหนึ่ง Merge ก่อน · แยกไฟล์แล้วไม่มี PR ไหนแก้ไฟล์เดียวกัน
> ⚠️ repo นี้เป็น **Public** · ห้ามใส่ข้อมูลจริงของครอบครัว (ชื่อ ที่อยู่ เลขโฉนด เลขบัญชี จำนวนเงิน)

## ชื่อไฟล์

`YYYY-MM-DD-<ชื่อ branch ไม่มี prefix>.md` เช่น `2026-11-02-lease-print.md` (branch `feat/lease-print`)

- ตั้งชื่อได้ตั้งแต่ commit แรก ไม่ต้องรอเลข PR · เรียงตามวันที่เองเมื่อ `ls`
- ได้เลข PR แล้ว ใส่เลขในหัวไฟล์ (แก้ไฟล์ของตัวเอง ไม่ชนใคร) · ห้ามแก้ไฟล์ของ PR อื่น ยกเว้นตั้งใจแก้ข้อมูลที่ผิด
