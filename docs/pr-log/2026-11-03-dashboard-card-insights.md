## เปลี่ยนอะไร
เจ้าของเห็นว่าเส้นเล็กในการ์ดซ้ำกับกราฟ Net Worth ใหญ่ จึงเลือกแบบ 1 + 2 + 3 (`src/app/(app)/page.tsx`):
- **การ์ดสินทรัพย์ · แถบสภาพคล่อง**: แถบฟ้า "ได้เงินเร็ว X%" (เงินฝาก / เงินสด + การลงทุน) และส่วนที่เหลือ "ใช้เวลาขาย Y%" (อสังหาฯ ธุรกิจ เงินให้กู้ ประกัน สินทรัพย์อื่น) · ใช้รายการชุดเดียวกับกล่องสัดส่วน (`month_family_items` / `month_person_items` · ไม่ถามฐานข้อมูลเพิ่ม)
- **การ์ดหนี้สิน · ระดับหนี้**: แถบหนี้สิน ÷ สินทรัพย์ สีตามระดับ (เขียว ต่ำกว่า 30% · เหลือง 30–50% · แดง เกิน 50% · มีขีดที่ 30% / 50%) + คำว่า หนี้ต่ำ / ปานกลาง / สูง (ไม่มีหนี้ = "ไม่มีหนี้")
  - บรรทัดล่าง = "ค่างวด X บาท/เดือน" สูตรเดียวกับ "ค่างวดรวม" หน้า Liabilities (เงินกู้ ACTIVE สกุล THB · รายคน × สัดส่วนหนี้) · เป็นค่างวดปัจจุบัน ไม่ขึ้นกับเดือนที่เลือก · ไม่มีค่างวด = "ณ วันนี้" เหมือนเดิม
- **การ์ด Net Worth · เปลี่ยนไปในแต่ละช่วง**: เดือนนี้ · ตั้งแต่ต้นปี (เทียบสิ้นปีก่อน) · ตั้งแต่ Go-live (เทียบยอดตั้งต้น) เป็น % (ชี้ = ยอดบาท) · ช่วงที่ฐานเป็นวันเดียวกันแสดงครั้งเดียว → ปีนี้ (Go-live ต.ค. 2569) ยังไม่มี "ตั้งแต่ต้นปี" จะเริ่มขึ้นเดือน ม.ค. 2570
- เอาเส้นเล็ก (`Sparkline` / `CardSpark`) ออกจากทั้ง 3 การ์ด รวมตอนดูรายคน · การ์ดสูงเท่ากัน (แถวข้อมูลจองที่ไว้ระหว่างโหลด)
