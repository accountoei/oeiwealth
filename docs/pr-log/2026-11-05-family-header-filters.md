## เปลี่ยนอะไร
- **ตัวกรอง "ทั้งครอบครัว" ขึ้นแถบบน** (ตำแหน่งเดียวกับ Investments / Liabilities · `HeaderFilters`): Membership & Points · Health · Tax · Donations (ผู้บริจาค)
- **Tax**
  - ไม่เลือกคน = ทั้งครอบครัว (ค่าเริ่มต้นทุกบทบาท) · บทบาทอื่นเห็นแถวของตัวเองแถวเดียว (รายชื่อ = ตัวเอง · RLS ของแบบภาษี)
  - ตัวเลือกปีภาษี: รายบุคคลอยู่ในกล่องแรกข้างชื่อ · ทั้งครอบครัวอยู่ที่หัวกล่อง (`YearSelect`)
  - ลิงก์ `?p=` ที่ไม่ถูก / ไม่มีสิทธิ์ → กลับไปทั้งครอบครัว · ลบ `TaxFilters`
- **Donations**
  - 4 กล่องเล็กรวมเป็นกล่อง "สรุปการบริจาค" · ตัวเลือกปี (`UrlSelect`) ข้างหัวกล่อง · ปุ่ม "+ บันทึกการบริจาค" มุมขวาบน
  - ตัวกรองผู้บริจาค (`DonorFilter` แทน `DonationFilters`) ตัวเลือกแรก "ทั้งครอบครัว"
  - เลิกใช้ผู้บริจาคแบบ "ไม่ระบุ / กลุ่ม": ฟอร์มเลือกได้แค่สมาชิก / กิจการ (แบบกลุ่มเหลือเฉพาะตอนแก้รายการเดิม) · ตัวเลือกกรองและคอลัมน์ "กลุ่ม (ข้อมูลเดิม)" แสดงเฉพาะเมื่อยังมีรายการกลุ่มเหลือ
  - SQL ย้ายรายการ GROUP ทั้งหมด (prod 391 รายการ ปี 2539–2560 ชื่อเดียวกันทั้งหมด) ไปเป็นผู้บริจาคกิจการ (ระบุ asset id · ไม่ใส่ชื่อจริงใน repo) · ไม่พบกิจการ = ไม่แก้อะไร · รันซ้ำได้ · ทดสอบในเครื่อง: ย้าย 2 → 0 รอบสอง
- **Documents**: 4 กล่องเล็กรวมเป็นกล่อง "ภาพรวมเอกสาร" · ปุ่ม "+ อัปโหลดเอกสาร" + "เปิดโฟลเดอร์" มุมขวาบน · ช่อง "ยังไม่ผูก" ยังกดกรองได้ · ปุ่ม primary ของ `DocumentUpload` ใช้ `ROW_BTN`

## การตัดสินใจ (owner 5 พ.ย. 2026)
- แถบบน = "ของใคร" (คน / ผู้บริจาค) · ในกล่อง = "ปีไหน"
- ไม่มีการบริจาคแบบไม่ระบุผู้บริจาคอีก · รายการกลุ่มเดิม → กิจการ OEI (ถ้า owner เลือกย้าย)
