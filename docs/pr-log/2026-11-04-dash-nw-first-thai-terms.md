## เปลี่ยนอะไร
- **การ์ดบน Dashboard** (`TopCards` / `Big` / `CardSkeleton`): ความมั่งคั่งสุทธิเป็นใบแรก (ซ้ายสุด · มือถือ = เต็มแถวบนสุด) → สินทรัพย์ → หนี้สิน · พื้นฟ้าอ่อนแบบเดิม (`HERO_BG` / `TONE` · เทียบ 3 แบบแล้วเจ้าของเลือก ก.)
- **กล่องสัดส่วนตามหมวด + กล่องรายบุคคล**: % ตัวหนา · ยอดเงินตัวธรรมดา · ไม่มีเส้นคั่นแถว (แถบสีคั่นอยู่แล้ว) · คงเส้นเหนือ "รวมครอบครัว"
- **แถวหนี้สิน** (กล่อง + pop up): % ของสินทรัพย์รวม สีแดง (ทศนิยมแบบการ์ดหนี้สิน เช่น 0.11%) + แถบแดงบนรางเทา
- **Net Worth → ความมั่งคั่งสุทธิ** ในข้อความที่ผู้ใช้เห็นทั้งระบบ (~60 จุด: Dashboard · ปิดเดือน · Property · Loans · Investments · Insurance · Family · Settings) · หัวกล่องกราฟ = "ความมั่งคั่งสุทธิ (Net Worth) · …" ที่เดียว
- **สินทรัพย์ / ทรัพย์สิน** ตามกติกา: Alternative Assets (ฟอร์มเพิ่ม · ปุ่ม + เพิ่มทรัพย์สิน · ตารางบันทึกทั้งชุด · ข้อความผิดพลาด) ใช้ "ทรัพย์สิน" สำหรับรายการ · หมวด Opening Setup "สินทรัพย์อื่น" · คำอธิบายเว็บ "สินทรัพย์และหนี้สิน" · ตัวอย่างฟอนต์ "ความมั่งคั่งสุทธิ"
- **AGENTS.md**: เพิ่มกติกาคำศัพท์ (สินทรัพย์ / ทรัพย์สิน · ความมั่งคั่งสุทธิ · Bank Accounts · เงินฝากธนาคาร)

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| ลำดับการ์ดบน | ความมั่งคั่งสุทธิใบแรก (4 พ.ย. 2026 · เดิมขวาสุดตั้งแต่รอบ 3) |
| สีการ์ดความมั่งคั่งสุทธิ | ก. พื้นฟ้าอ่อนแบบเดิม (เทียบกับน้ำเงินเข้ม / น้ำเงินสดแล้ว) |
| ตัวหนาในกล่องสัดส่วน / รายบุคคล | % หนา ยอดเงินไม่หนา · ไม่มีเส้นคั่นแถว |
| หนี้สินในกล่องสัดส่วน | % ของสินทรัพย์รวม สีแดง + แถบแดง |
