- SQL: ไม่มี SQL · ไม่มี Edge Function
- ทดสอบ: tsc / eslint / build ผ่าน · ตรวจหน้าจอด้วยข้อมูลสมมติ 9 คน (เลื่อนตารางไปทางขวา) · ไม่ได้รัน scenario tests (ไม่แก้ฐานข้อมูล)

## เปลี่ยนอะไร
- ตารางทั้งครอบครัว: คอลัมน์ "ความคุ้มครอง" ล็อกไว้ทางซ้าย (sticky) · ชื่อกลุ่ม (สุขภาพ / ชีวิตและอุบัติเหตุ …) ก็ค้างไว้ · สมาชิกเพิ่มจนเกินจอ เลื่อนซ้าย-ขวาได้โดยยังเห็นชื่อแถว
- เลื่อนเฉพาะตาราง: หัวกล่อง / ปุ่ม "พิมพ์สรุปสำหรับโรงพยาบาล" / คำอธิบายอยู่กับที่ (เดิมเลื่อนทั้งกล่อง)
- กล่อง "เรื่องที่ควรดู": เอา "เบี้ยเลยกำหนด" และ "ครบ / ต่ออายุใน 60 วัน · เลยวันสิ้นสุด" ออก (มีในแท็บภาพรวมแล้ว: การ์ดเบี้ยรวม + คอลัมน์สถานะของตารางกรมธรรม์) · เหลือ 4 เรื่อง: กรมธรรม์สุขภาพที่ยังไม่กรอกความคุ้มครอง · วงเงินต่อปีใช้ ≥ 80% · คนที่ไม่มีประกันสุขภาพ · คนที่ไม่มีทุนชีวิต
- ไม่มีเรื่อง = ไม่แสดงกล่อง (เอากล่องเขียว "ไม่มีเรื่องที่ต้องติดตาม" ออก)
- เลือกคน: คอลัมน์ "สิ้นสุด" แสดง "เลยวันสิ้นสุด" (แดง) เพิ่มจาก "ใกล้ครบ"
