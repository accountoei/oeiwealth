## เปลี่ยนอะไร
- **pop up "Net Worth เปลี่ยนเพราะอะไร"** (`DashDetail.tsx`):
  - บรรทัด "± มูลค่าเปลี่ยน / อื่น ๆ" กางแล้วเห็นเฉพาะส่วนที่เป็น "อื่น ๆ" แยกตามหมวด (`OtherTable`) · รวมแล้ว = ตัวเลขบรรทัดพอดี
    - "เงินฝาก / เงินสด + การลงทุน" = ส่วนที่เหลือหลังหักหมวดอื่น (= ยอดเปลี่ยนของสองหมวดนี้ − รายได้ / ค่าใช้จ่าย / กำไร / ขาดทุนข้างบน)
    - หมวดอื่น = ยอดเปลี่ยนทั้งหมวด · แสดงเฉพาะแถวที่ไม่ใช่ 0
  - ตาราง "มูลค่าตามหมวด ต้นงวด → สิ้นงวด" (มีแถวการลงทุนเต็มหมวด) ย้ายไปเป็นบรรทัดสุดท้ายแยก "ยอดตามหมวด ต้นงวด → สิ้นงวด · รวมผลของทุกบรรทัดข้างบน" → ไม่ดูเหมือนนับการลงทุนซ้ำ
- **กล่อง "สัดส่วนสินทรัพย์ตามหมวด"** และ pop up (`page.tsx` · `Allocation` / `AllocationDetail` / `AllocRow` / `StackBar` / `sortedGroups`):
  - แถบรวม 100% แบ่งสีตามหมวดด้านบน · หมวดเรียงมาก → น้อย (หมวดที่ยังไม่มีรายการอยู่ท้าย · หนี้สินท้ายสุด)
  - ยอดเงินตัวหนา แล้ว % ตัวบางสีเทาเข้มอยู่หลังยอด (คอลัมน์กว้างคงที่ → % ตรงกันทุกแถว) · แถบหนา 10px · หนี้สินไม่มีแถบ
  - สีหมวดสดขึ้น ชุดเดียวกับกล่องเงินฝากตามธนาคาร (`GROUP_COLOR`) · ประกัน = เขียวมะนาว (ไม่ใช้ชมพู ใกล้แดงหนี้สิน)
- **กล่อง "Net Worth รายบุคคล"**: ยอดก่อน แล้ว % หลังยอด (รวมบรรทัด "รวมครอบครัว")
- **การ์ดสินทรัพย์**: "ได้เงินเร็ว / ใช้เวลาขาย" → "สภาพคล่องสูง / สภาพคล่องต่ำ"

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| ตารางใต้ "อื่น ๆ" ซ้ำกับบรรทัดกำไร / ขาดทุน | แบบ ก.: ตารางยอดทุกหมวดเป็นบรรทัดสุดท้ายแยก · "อื่น ๆ" แสดงเฉพาะส่วนที่เหลือ (4 พ.ย. 2026) |
| กล่องสัดส่วนเทียบยาก | แบบ ข.: แถบรวม 100% + เรียงมาก → น้อย (4 พ.ย. 2026) |
| ตัวเลข / % | ยอดหนา · % บางอยู่หลังยอด ทั้งกล่องสัดส่วนและรายบุคคล · % ไม่ใช้สีน้ำเงิน (สีน้ำเงิน = กดได้) |
| คำบนการ์ด | สภาพคล่องสูง / สภาพคล่องต่ำ |
