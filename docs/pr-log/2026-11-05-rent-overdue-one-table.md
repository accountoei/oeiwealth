## เปลี่ยนอะไร
- **ยกงวดค้างมาเดือนใหม่**
  - Property แท็บรับค่าเช่า: งวดเดือนนี้ + งวดก่อนที่ยังค้างรับ (ตั้งแต่ go-live) + งวดก่อนที่รับในเดือนนี้ (ยังเห็นหลังบันทึก พร้อม "รับแล้ว … ✎") · `withCarried` ใน `property/page.tsx`
  - Property แท็บค่าใช้จ่าย: แบบเดียวกันกับค่าใช้จ่ายประจำ · งวดเดือนก่อนมีบรรทัด "งวด ต.ค. 2569" ใต้วันครบกำหนด (แดง = ค้างจ่าย) · หัวกล่อง "+ ค้างจ่ายยกมา"
  - หน้ารายรับรายจ่าย: รายได้ที่คาดไว้ (ค่าเช่า / รายได้ประจำ) ยกงวดที่เลยกำหนดจากเดือนก่อน แบบเดียวกับเงินให้กู้ / ประกัน / ค่าใช้จ่ายประจำที่ทำอยู่แล้ว · บันทึกรับลงงวดของแถวนั้น (`period={e.income_period}`)
- **แท็บรับค่าเช่า = ตารางเดียว** (เดิม 3 ตาราง: รับค่าเช่า / รายได้จากทรัพย์สินที่บันทึกแล้ว / สัญญาเช่าที่มีผล) · `RentBatch.tsx`
  - แถวแรกของแต่ละสัญญา: ห้อง · ผู้เช่า · ระยะสัญญา · ป้ายสถานะ (ไม่แสดงเมื่อ "มีผล") · ลิงก์พิมพ์สัญญา · ค่าเช่า /เดือน /ไตรมาส
  - สัญญาที่ไม่มีงวดเดือนนี้ (รายไตรมาส / รายปี / ยังไม่เริ่ม) มีแถว "ไม่มีงวดเดือนนี้ · งวดถัดไป …" / "เริ่มสัญญา …" ไม่มีช่องกรอก
  - รายได้อื่นที่รับในเดือนนี้ (ค่าน้ำไฟที่รับคืนแล้ว · ค่าเช่างวดอื่น ฯลฯ) ต่อท้ายตาราง กดยอดแก้ได้เหมือนเดิม
  - บรรทัดสุดท้าย "รับเข้าเดือนนี้รวม (ตามวันที่รับ)" = ตัวเลขเดียวกับการ์ดภาพรวม · กรองทรัพย์สินแล้วรวมใหม่
  - กล่องตัวกรองด้านบนแยกไว้เหมือนเดิม (แบบแท็บรับของ Investments)
- **ช่องราคาซากขึ้นลูกน้ำตอนพิมพ์**: `NumberInputs.tsx` รองรับ `data-num="pct"` (ใส่ได้ทั้งเงินหรือ %) · ใช้ที่ตารางส่วนประกอบ + ฟอร์ม "+ สิ่งปลูกสร้างใหม่" · ใช้แป้นพิมพ์เต็ม (iPad / มือถือพิมพ์ % ได้) · AGENTS.md เพิ่มกติกานี้
