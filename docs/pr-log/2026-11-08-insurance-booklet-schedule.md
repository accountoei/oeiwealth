## เปลี่ยนอะไร
- **ปุ่ม "แก้ตารางเบี้ย" ปุ่มเดียวทั้งเล่ม** (เล่มที่มีสัญญาเพิ่มเติม · `BookletScheduleEditor.tsx` แทนปุ่มละส่วน)
  - 1 แถว = 1 วันครบกำหนด · คอลัมน์ละส่วน (ชีวิต / สุขภาพ …) + **รวม** · ช่องว่าง = ส่วนนั้นไม่มีงวดวันนั้น · หมายเหตุ / ไม่ได้จ่าย ต่อแถว
  - ช่องที่จ่ายแล้วล็อก 🔒 · แถวที่มีส่วนที่จ่ายแล้วแก้วันที่ / ลบแถวไม่ได้ แต่ใส่ยอดของส่วนที่ยังไม่จ่ายได้
  - สูตรยอดเท่ากันทุกงวด **ทีละส่วน** (เลือกส่วน → คำนวณ · ส่วนอื่นไม่ถูกแตะ) · "+ แทรก" / "ยอดนี้ ↓" / "ลบ" / "+ เพิ่มงวดท้ายตาราง"
  - อัปโหลด .xlsx / วางจาก Excel **หลายคอลัมน์**: วันครบกำหนด · ยอดส่วนที่ 1 · ยอดส่วนที่ 2 … (ช่องว่าง / "-" / 0 = ไม่มีงวด)
  - บันทึกทุกส่วนพร้อมกัน (`set_insurance_booklet_schedule` ใหม่ · วนใช้ `set_insurance_schedule` เดิมทีละส่วน) · ผิดส่วนเดียว = ไม่บันทึกเลย · ข้อความผิดบอกชื่อส่วน
  - สัญญาเพิ่มเติมประเภทเดียวกันหลายฉบับ: หัวคอลัมน์ต่อชื่อแบบ (เช่น "สุขภาพ · มะเร็ง…")
  - กรมธรรม์ที่ไม่มีสัญญาเพิ่มเติม: ปุ่มเดิม (`InsScheduleEditor`)
- **แก้ตารางมูลค่าเวนคืนแล้ว ยอดที่ระบบลงให้ขยับตาม** (`set_insurance_cash_value_table`)
  - ขยับเฉพาะยอดที่ระบบลงตามตาราง (หมายเหตุ "ตามตารางมูลค่าเวนคืนในสัญญา · สิ้นปีกรมธรรม์ที่ N") ที่วันที่ไม่เปลี่ยน และยอดยังเท่าตารางเดิม
  - ไม่แตะ: ยอดที่แก้เอง / ตามหนังสือแจ้ง / ยอดตั้งต้น · ก่อน Go-live · เดือนที่ปิดแล้ว
  - ข้อความหลังบันทึก: "· ปรับยอดที่ลงไว้ตามตารางใหม่ N ปี"
- **ปุ่ม "บันทึกรับเงิน" ต่อเคลม** (กล่องเคลม · `ClaimReceiveForm.tsx`) เลือก 2 แบบ
  - **เงินคืนค่าใช้จ่ายที่จ่ายเองไปก่อน** (ค่าใช้จ่ายที่ตั้ง "ได้เงินคืน" สกุลเดียวกับเคลม) → `record_reimbursement` เดิม ผูกเคลม · ลดค่าใช้จ่าย ไม่ใช่รายได้
  - **เงินชดเชย / สินไหม** (ไม่ได้คืนค่าใช้จ่าย) → รายได้ "ผลประโยชน์ประกัน" ผูกเคลม (`receive_insurance_claim` ใหม่ · คอลัมน์ใหม่ `income_transactions.insurance_claim_id`) · รายได้ของผู้เอาประกัน (เปลี่ยนได้)
  - ทั้ง 2 แบบเข้าบัญชีที่เลือก (สกุลเดียวกับเคลม) · ยอดรับรวมเกินยอดเคลมไม่ได้ · เคลมที่ปฏิเสธ / ยกเลิกรับไม่ได้
  - ยอด "ได้รับ" + สถานะเคลมอัปเดตเอง (`private.refresh_claim` นับทั้งเงินคืน + รายได้ · ลบเงินที่ผูกหมด → ได้รับ 0 และสถานะกลับเป็น "ยื่นแล้ว")
  - กล่องเคลมแสดง "รับเงินเคลม วันที่ ยอด · เข้า <บัญชี> · รายได้" ใต้เคลม · แก้ / ลบเงินที่รับแล้วที่ Income & Expenses
