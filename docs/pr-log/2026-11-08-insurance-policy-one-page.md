## เปลี่ยนอะไร
- **หน้ากรมธรรม์ไม่มีแท็บแล้ว** (`insurance/[id]/page.tsx`) · เรียงเป็นแถว (ขอบกล่องตรงกัน):
  - แถวบน: มูลค่าเวนคืน + เอกสาร (ซ้าย) | รายละเอียด (ขวา) — เหมือนเดิม
  - แถวกลาง: **เคลม** (ซ้าย ใต้เอกสาร) | **ความคุ้มครอง** (ขวา ใต้รายละเอียด)
  - ล่างสุด เต็มความกว้าง: ตาราง **"มูลค่าเวนคืน เบี้ยประกัน และผลประโยชน์"** (เล่มที่ไม่มีมูลค่าเวนคืน = "เบี้ยประกันและผลประโยชน์" · ประกันทรัพย์สิน = "ตารางเบี้ย")
  - ลิงก์เดิม `?tab=flow / premium / benefit / cv` (จาก Income & Expenses · Property · บัตรเครดิต) = เปิดหน้าแล้วเลื่อนลงไปที่ตารางเอง (`ScrollToId.tsx`)
- **กล่องเคลม** (แคบ · 1 เคลม = 2 บรรทัด): วันยื่น · ส่วนของเล่ม · ยอดเคลม / สถานะ (สี) · เกิดเหตุ · ได้รับ · **รอรับ**
  - บรรทัดบนกล่อง "รอรับ … · N เคลม" = ยอดเคลม − ได้รับ ของเคลมที่ยื่นแล้วยังไม่จบ (ยื่นแล้ว / อนุมัติ / จ่ายบางส่วน · ร่างไม่นับ) — ยังไม่นับเป็นรายได้ / ความมั่งคั่งสุทธิ
  - เงินคืนที่ผูกกับเคลม: "รับคืน วันที่ ยอด · เข้า <บัญชี>" + ค่าใช้จ่ายต้นทาง
  - กดแถว = แก้ / ลบเคลม (เหมือนเดิม) · ⓘ อธิบายวิธีบันทึกกรณีจ่ายเองไปก่อนแล้วรอเคลม
- **มูลค่าเวนคืนในตาราง** — ตัวเลขตามสัญญาบอกสถานะ:
  - ตัวจาง = ยังไม่ถึง · ขีดเส้นใต้ = ถึงแล้วยังไม่ได้ลง (กด = ลงยอดของปีนั้น) · **สีฟ้า = ลงแล้ว** (กด = แก้ยอดที่ลง เช่น รวมเงินปันผลตามหนังสือแจ้ง / ลบ)
  - ยอดที่ลงตรงกับตารางของปีที่มีผล ณ วันนั้น = **ไม่มีแถวแยก** (เช่น ยอดตามหนังสือแจ้งที่เท่ากับปีที่ 9) · ยอดที่ไม่ตรง (ยอดตั้งต้น / หนังสือแจ้งที่รวมปันผล) = แถวย่อยสีฟ้า "ลงแล้ว" กดแถวเพื่อแก้ / ลบ
  - เอาปุ่ม **"ปรับมูลค่าเวนคืน"** และ **"+ เพิ่มมูลค่าเวนคืน"** ออก (`AddCashValueForm` · `addCashValue`)
- **แก้ตารางมูลค่าเวนคืน** แบบตารางเหมือนตารางเบี้ย / ผลประโยชน์ (`CvTableEditor.tsx` แทน `CashValueTableEditor`)
  - 1 แถว = ปีกรมธรรม์ · สิ้นปีกรมธรรม์ / วันที่ (ค่าตั้งต้น = วันครบรอบ แก้ได้ เช่น วันที่ในหนังสือแจ้ง) · มูลค่า · สถานะ (ลงแล้ว / ยังไม่ถึง / ก่อน Go-live / ถึงแล้ว · รอลง)
  - "+ แทรก" / "ลบ" ต่อแถว · "+ เพิ่มปีท้ายตาราง" · อัปโหลด .xlsx / วางจาก Excel แล้ว "ใส่ลงตาราง" · บันทึกทั้งตาราง (`set_insurance_cash_value_table` เดิม)
  - เล่มที่ไม่มีตารางในสัญญา: ใส่ยอดตามหนังสือแจ้งเป็นแถว (ปี + วันที่ในหนังสือ) ในตารางเดียวกัน · ระบบสร้าง / ลงมูลค่าเวนคืนให้เอง
  - ตัวช่วยใน `src/lib/insurance-grid.ts`: `cvAutoDate` · `cvSetYear` · `cvNextRow` · `sortCvGrid` · `cvGridToLines` (+ เทสต์ใน `scripts/insurance-grid.test.mjs`)
- ตารางเบี้ย / ผลประโยชน์ (`InsScheduleEditor`): ปุ่มต่อแถวเป็น "+ แทรก" / "ลบ" ตามกติกาปุ่ม (เดิม ✕ สีแดง) · ข้อความ "แท็บเบี้ยและผลประโยชน์" → "ตารางของหน้ากรมธรรม์"
- ความคุ้มครองอยู่ในกล่อง 2 ใน 3 → คอลัมน์ชื่อ / วงเงินแคบลงเล็กน้อย ให้หมายเหตุไม่ตกบรรทัดมาก
