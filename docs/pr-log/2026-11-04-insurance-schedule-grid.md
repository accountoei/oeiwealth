  - งวดก่อน Go-live มีป้าย "ก่อน Go-live" · งวดที่จ่าย / รับแล้วล็อก (🔒 แก้ที่แถวการจ่าย / รับในแท็บ) · ตรวจก่อนบันทึก (วันที่ว่าง · ยอดไม่ใช่ตัวเลข / ≤ 0 · งวดหลัง Go-live อยู่ก่อนงวดที่ชำระแล้ว) · หัวตารางแสดงจำนวนงวด / ยอดรวม / ล็อกกี่งวด / ก่อน Go-live กี่งวด
  - บันทึก = แทนงวดที่ยังไม่ชำระทั้งชุด (ถามยืนยันก่อน) · ลบทุกงวดแล้วบันทึก = ลบงวดที่ยังไม่ชำระ
