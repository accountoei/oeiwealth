- `src/components/RowPanel.tsx`: แถวที่กดเพื่อแก้ไขได้ หาเองว่าช่องแรกที่มีแต่ยอดเงิน (ทศนิยม 2 ตำแหน่ง มี / ไม่มีสกุลเงิน) คือช่องไหน แล้วใส่ `data-amt-auto` · ไม่นับตัวเลขในปุ่ม / ลิงก์ · ถ้าในแถวมี `data-amt` อยู่แล้วใช้อันนั้น
- `globals.css`: `[data-amt]` / `[data-amt-auto]` ในแถวที่กดได้ = ขีดเส้นประ (ชี้เมาส์ = สีฟ้า) · กดตัวเลขหรือกดแถวเปิดหน้าต่างเดียวกัน · ผู้ดูอย่างเดียว (VIEWER) แถวกดไม่ได้ จึงไม่มีเส้นประ
- ใช้ได้ทุกหน้าที่ใช้ `RowActions` / `PairEdit` / `useRowPanel` ประมาณ 30 หน้า โดยไม่ต้องแก้ทีละหน้า
- หน้ากรมธรรม์ (`insurance/[id]/page.tsx`): มีตารางมูลค่าเวนคืนแต่ไม่มีตารางผลประโยชน์ (เช่น ประกันแบบมีโบนัส) แสดงกล่องสรุป (จ่ายเบี้ยแล้ว · รับผลประโยชน์แล้ว · สุทธิถึงวันนี้ · จุดคุ้มทุนถ้าเวนคืน) + คอลัมน์สุทธิสะสม + ป้ายเวนคืนคุ้มทุน · ไม่แสดง "ถ้าไม่เวนคืน" และคำแนะนำเรื่องเงินครบสัญญาเมื่อไม่มีผลประโยชน์
- `AGENTS.md`: กติกา "เส้นประ = กดได้"
