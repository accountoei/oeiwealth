- **เส้นเฉลี่ย 3 ปี** (เส้นประ) บนกราฟรายได้และกำไร: ค่าเฉลี่ยของยอดรวมปีนั้น + 2 ปีก่อนหน้า (ต้องมีครบ 3 ปี) · คิดจากทุกปีก่อนตัดช่วง 3 / 5 / 10 ปี · ปุ่ม "เส้นเฉลี่ย 3 ปี [แสดง / ซ่อน]" (ค่าเริ่มต้นแสดง) · โหมดแยกตามบริษัท = เส้นของยอดรวม · ชี้ที่ปีเห็นค่าในกล่องค่า
- **ลิงก์ชื่อบริษัท** (แท็บภาพรวม · ผลประกอบการ · อัปเดตมูลค่า · บันทึกรับเงินปันผล) ใช้ `IntentLink` แบบเมนูซ้าย: ชี้ค้าง 0.15 วินาที / แตะ → โหลดทั้งหน้ารอไว้ → กดแล้วขึ้นเร็ว (เดิมโหลดล่วงหน้าแค่โครงหน้า แล้วดึงข้อมูลหลังกด 3 รอบติดกัน · คำสั่งฐานข้อมูลเองใช้เวลา < 0.05 วินาที)
