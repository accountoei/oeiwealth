- หน้าภาพรวม Insurance (`insurance/page.tsx`): กล่องสรุป 4 กล่อง + กล่องสัดส่วน 2 กล่อง + บรรทัดสรุปเหนือตารางกรมธรรม์ รวมกรมธรรม์สกุลอื่น โดยแปลงเป็นบาทด้วยอัตราล่าสุด (`v_fx_status.rate_to_thb` แบบหน้า Bank Accounts)
  - หัวกล่องเป็น "(THB Equivalent)" · ใต้กล่องมียอดแยกตามสกุล `CcyBreakdown` (ใหม่ใน `src/components/Boxes.tsx`: THB ก่อน · สกุลอื่น ≈ บาท · มีแต่บาท = ไม่แสดง)
  - กล่องตามบริษัทประกัน: แถวสกุลอื่นมี "USD …" ต่อท้ายจำนวนฉบับ · บรรทัด "ไม่รวมกรมธรรม์สกุลเงินอื่น N ฉบับ" เปลี่ยนเป็นยอดแยกตามสกุล
  - กล่องตามสมาชิก: ทุนประกันชีวิต / มูลค่าเวนคืนรวมส่วนสกุลอื่น (บาท) · ด้านล่างแยกตามสกุลทั้ง 2 คอลัมน์
- แท็บความคุ้มครอง (`CoverageTab.tsx`): ช่องที่มีสกุลอื่นแสดงยอดรวมเป็นบาท + บรรทัดเล็ก "รวม USD" · หน้าต่างรายละเอียดแสดงแต่ละกรมธรรม์ในสกุลจริง (+ ≈ บาท) และอัตราที่ใช้ · "อื่น ๆ" ที่ไม่มีวงเงินแสดง "มี" แทน 0.00 · ใบพิมพ์สำหรับโรงพยาบาลไม่เปลี่ยน (สกุลจริง)
- หน้ากรมธรรม์ ตาราง "มูลค่าเวนคืน เบี้ยประกัน และผลประโยชน์": ข้อความสรุป / คำอธิบายใต้หัวข้อย้ายเข้า ⓘ ข้างหัวข้อ · เหลือบรรทัดเตือน (เบี้ยเลยกำหนด · มูลค่าเวนคืนยังไม่ได้ลง) เมื่อมี
- `FlowTable.tsx`: หมายเหตุของแถว (และข้อความแถวย่อยมูลค่าเวนคืน) บรรทัดเดียว ตัดด้วย … · กดเพื่อขยาย / ย่อ · ชี้เมาส์บนคอมฯ เห็นข้อความเต็ม

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| สกุลเงินอื่นในหน้าภาพรวม / ความคุ้มครอง | รวมเป็นบาท (THB Equivalent · อัตราล่าสุด) + แสดงยอดแยกตามสกุลใต้กล่อง / ในหน้าต่างรายละเอียด |
| ใบพิมพ์สำหรับโรงพยาบาล | คงสกุลจริง ไม่แปลง |
| หมายเหตุยาวในตาราง | บรรทัดเดียว + กดขยาย (ไม่ใช้ข้อความลอย เพราะ iPad ไม่มีชี้เมาส์) |
