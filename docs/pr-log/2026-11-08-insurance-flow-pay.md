## เปลี่ยนอะไร
- หน้ากรมธรรม์ ตารางเบี้ยและผลประโยชน์ (`[id]/page.tsx`, `[id]/FlowTable.tsx`, ใหม่ `[id]/FlowRecord.tsx`)
  - **ปุ่ม 2 ปุ่มคู่กันเหนือตาราง** (ขวาสุดของแถวปุ่ม) แทนปุ่มรายแถว
    - **บันทึกรับ**: ในหน้าต่างเลือกได้ 2 แบบ — *รับผลประโยชน์ตามงวด* / *รับเงินก้อน (ครบสัญญา / เวนคืน / สินไหม)* · ปุ่ม "รับเงินก้อน" เดิมที่หัวหน้ารวมเข้ามาแล้ว
    - **บันทึกจ่าย**: เบี้ยหลายงวด / ทุกส่วนของเล่มในครั้งเดียว (จ่ายจากบัญชี / บัตรเดียวกัน = หน้าบัญชีแสดงยอดรวมแถวเดียวเหมือนเดิม)
    - แบบเงินกู้: เลือกวันที่ → เติมยอดค้างของงวดที่ครบถึงวันนั้น (อย่างน้อยงวดค้างล่าสุด หรืองวดถัดไป) · แก้ยอดเองได้ · ช่องว่าง = ไม่บันทึกงวดนั้น · ปุ่ม "+ งวดถัดไป" สำหรับจ่าย / รับล่วงหน้า · "ตามงวด" = เติมใหม่
    - ไม่มีงวดเบี้ยค้าง = ปุ่มบันทึกจ่ายจาง · ไม่มีงวดผลประโยชน์รอรับ = เปิดที่ "รับเงินก้อน"
  - **เงินที่จ่าย / รับจริง = แถวของตัวเอง ตามวันที่จ่าย / รับจริง** (เดิมเป็นแถวย่อยใต้งวด)
    - เช่น รับเงินครบสัญญาบางส่วนวันนี้ = แถว "รับ" อยู่ปีที่รับ · แถวงวดครบสัญญายังบอก "รับแล้ว … · ค้าง …" · บรรทัดเล็กบอกงวดที่รับ ("งวดครบ …")
    - แถวจ่าย: ยอดอยู่ในคอลัมน์เบี้ย (เล่มที่มีสัญญาเพิ่มเติม = แยกคอลัมน์ตามส่วน) · งวดที่ = งวดที่จ่าย · ป้าย "จ่าย" + จากบัญชีไหน
    - สุทธิสะสมนับเงินจริง ณ วันที่จ่าย / รับ + งวดก่อน Go-live (เต็มงวด) + งวดที่ยังค้าง (คาดการณ์ ณ วันครบกำหนด) — `cashNet` ใน `src/lib/insurance-flow.ts`
  - **แก้ / ลบเงินจริงได้เฉพาะรายการล่าสุดของแต่ละฝั่ง** (จ่าย / รับ) โดยกดที่แถว · ไม่มีปุ่ม "ยกเลิกทั้งก้อน" แล้ว
    - แถวรับล่าสุด → แก้วันที่ / ยอด / บัญชี / หมายเหตุ / ถอนจากมูลค่าเวนคืน หรือ "ลบรายการนี้" (ADMIN / EDITOR)
    - แถวจ่ายล่าสุด: รายการเดียว = กดแถว · หลายงวด / หลายส่วนในชุดเดียว = กดยอดของแต่ละรายการ (เส้นประ)
  - แถวงวด: กดแถว = แก้งวด (วันครบกำหนด / ยอด / ได้จ่ายจริงไหม) เหมือนเดิม
  - หน้าต่างจ่ายเบี้ยรายงวดเดิมที่ถามต่อ "อัปเดตมูลค่าเวนคืนด้วยไหม?" ไม่มีในหน้านี้แล้ว (ลงยอดที่ช่องมูลค่าเวนคืนในตารางแทน · ระบบลงตามตารางในสัญญาให้เองเหมือนเดิม) · หน้า Income & Expenses ยังใช้หน้าต่างเดิม
- SQL ใหม่
  - `receive_insurance_benefits(p)` รับหลายงวดในคำสั่งเดียว (วัน / บัญชี / ผู้รับเงิน / หมายเหตุเดียวกัน · ผิดงวดเดียว = ไม่บันทึกเลย · ปิดกรมธรรม์ตอนรับงวดสุดท้ายในรายการ)
  - `edit_insurance_benefit_receipt(id, p)` แก้รายการรับล่าสุด = ยกเลิกของเดิม + บันทึกใหม่ในคำสั่งเดียว (งวด · ผลของการรับ · ผู้รับเงินคงเดิม) · แก้ได้เฉพาะรายการรับล่าสุดของกรมธรรม์ · ADMIN / EDITOR
  - **กันถอนจากมูลค่าเวนคืน 2 งวดของกรมธรรม์เดียวกันในคำสั่งเดียว** (ทั้งปุ่มใหม่และแท็บ "บันทึกรับผลประโยชน์" เดิม `batch_receive_insurance_benefits`)
    - เหตุผล: ทุกครั้งที่ถอน ระบบลงมูลค่าเวนคืนใหม่วันที่รับ · 2 งวดในคำสั่งเดียว = 2 ยอดวันเดียวกัน เวลาบันทึกเท่ากัน → ระบบเลือกยอดล่าสุดไม่ได้แน่นอน (ทดสอบในเครื่อง: ถอน 3 ครั้ง ๆ ละ 1,000 จาก 5,000 แล้วมูลค่าปัจจุบันขึ้น 4,000 แทน 2,000)
    - ไม่ถอนจากมูลค่าเวนคืน / มูลค่าเวนคืนเป็น 0 / คนละกรมธรรม์ = หลายงวดได้ · ตรวจข้อมูลจริงแล้ว ยังไม่มียอดซ้อนแบบนี้
    - หน้าต่างบันทึกรับเติมให้งวดเดียวเมื่อติ๊กถอนจากมูลค่าเวนคืน และเตือนถ้ากรอกเกิน
