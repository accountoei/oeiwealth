  - เงื่อนไขเดียวกับตอนบันทึกตาราง / จ่ายเบี้ย (`sync_insurance_cash_value`): กรมธรรม์ที่มีผล · ไม่อยู่ในเดือนที่ปิดงวด · เบี้ยก่อนวันนั้นจ่ายครบ (จ่าย / ประวัติ / ไม่ได้จ่าย)
  - เจ้าของ = ผู้เอาประกัน 100% (ไม่มี = ผู้จ่ายเบี้ย · ไม่มีทั้งคู่ = ข้าม) · วันก่อน Go-live = ยอดยกมา
  - เล่มที่สร้างไม่สำเร็จ = ข้ามไป นับไว้ใน `details.errors` ไม่ทำให้ทั้งงานล้ม (ขั้นคำนวณ Net Worth สิ้นเดือนยังทำต่อ)
  - ผลใน Settings → System (INSURANCE_CV): `added` (ปีที่ลงเพิ่ม) · `created` (รายการที่สร้างใหม่) · `policies` · `errors`
- **หน้า Insurance**: เอาแท็บ "อัปเดตมูลค่าเวนคืน" ออก (`CashValueBatch.tsx` · `batchCashValues` · `syncAllCashValues`) · เหลือ ภาพรวม · ความคุ้มครอง · บันทึกรับผลประโยชน์ · จ่ายชำระเบี้ยประกัน
- **หน้ากรมธรรม์**
  - เอาแท็บ "มูลค่าเวนคืน" ออก · ลิงก์เดิม `?tab=cv` เปิดแท็บเบี้ยและผลประโยชน์แทน
  - ตารางเบี้ยและผลประโยชน์มีคอลัมน์ **มูลค่าเวนคืน** ตามตารางในสัญญาทุกปี (`FlowTable` prop `showCv`)
    - ปีที่ตรงกับงวดเบี้ย = ตัวเลขอยู่แถวงวดนั้น · ปีที่ไม่มีงวดเบี้ย / ผลประโยชน์ = แถว "สิ้นปีกรมธรรม์ที่ N" (ป้าย "เวนคืน")
    - ปีที่ยังไม่ถึง = ตัวจาง · ปีที่ถึงแล้วแต่ยังไม่ได้ลง = กดตัวเลขเพื่อลงยอดของปีนั้น (เติมยอด / วันที่ / หมายเหตุให้)
    - ยอดที่ลงจริง = แถวย่อยสีฟ้า "ลงแล้ว" · กดแถวเพื่อแก้ / ลบ
    - ปุ่มกรอง "มูลค่าเวนคืน (N)" · กรองเบี้ย / ผลประโยชน์ ไม่แสดงแถวย่อยมูลค่าเวนคืน
    - มีคอลัมน์นี้ → ช่องวันที่ / รายการ / รับผลประโยชน์ แคบลง ให้ทั้งตารางพอดี iPad แนวนอนโดยไม่ต้องเลื่อนข้าง
  - ปุ่ม "แก้ตารางมูลค่าเวนคืนตามสัญญา" (หรือ "+ ตาราง…") · "+ เพิ่มมูลค่าเวนคืน" (เล่มที่ยังไม่มี) · "ปรับมูลค่าเวนคืน" · "ลงมูลค่าตามตาราง" ย้ายมาอยู่แถบบนของแท็บเบี้ยและผลประโยชน์ · หัวข้อซ้าย ปุ่มขวาขึ้นบรรทัดใหม่ได้
  - กล่องแรก (มูลค่าเวนคืน) แสดงข้อมูลปัจจุบันอย่างเดียว ไม่มีปุ่ม · เล่มที่ยังไม่มีมูลค่าเวนคืน = ข้อความบอกให้ใส่ตารางที่แท็บเบี้ยและผลประโยชน์
- **ฟอร์มเพิ่มกรมธรรม์**: เอาปุ่มติ๊ก "มีมูลค่าเวนคืน" + ช่องมูลค่า / วันที่ / ก่อน Go-live ออก (`createPolicy` ส่ง `has_cash_value: false`) · ใส่ตารางมูลค่าเวนคืนในหน้ากรมธรรม์หลังบันทึก
- `AssetValuationForm` รับ `defaultDate` · `AddCashValueForm` รับ `bare` (ปุ่มในแถบบน)
- แก้แถวที่ผิดใน `2026-11-08-insurance-property-headings.md` (#378): บันทึกตารางมูลค่าเวนคืนสร้างรายการมูลค่าเวนคืนให้เองได้อยู่แล้ว
