## เปลี่ยนอะไร
- ค่าใช้จ่าย "ค่าธรรมเนียมโอนเงิน (ต้นทาง / ปลายทาง …)" มีปุ่ม "แก้ไข" → เปิดหน้าต่างแก้การโอนต้นทาง (ค่าธรรมเนียมเป็นช่องหนึ่งของการโอน · ลบ = ลบการโอนทั้งรายการ) · `entry-kit.tsx` `expEdit` → `moveEdit`
- การโอน ธนาคาร ↔ พอร์ต ในตารางเงินเข้า–ออก (หน้า Income & Expenses + หน้าบัญชีธนาคาร) ใช้หน้าต่างช่องครบเหมือนหน้าพอร์ต: วันที่ · บัญชีเงินฝากในพอร์ต · เงินที่ออก · ค่าธรรมเนียมต้นทาง · ยอดที่เข้าจริง · ค่าธรรมเนียมปลายทาง · รายละเอียด (`PfTransferEditor.tsx` → `updateTransfer`) · เดิมมีแค่วันที่ / จำนวน / รายละเอียด · บัญชีในพอร์ตของรายการปิดไปแล้ว → ใช้ช่องแบบเดิม
- รายได้จากพอร์ต (ปันผล / ดอกเบี้ย / คูปอง) แก้ / ลบได้ในหน้าต่าง (แก้รายการในพอร์ตที่สร้างรายได้นี้: วันที่ · วันชำระ · ยอด · ค่าธรรมเนียม · ภาษี · หมายเหตุ) · ทั้งแท็บรายได้และแถวเงินเข้าบัญชีจากพอร์ต · `INC_SELECT` เพิ่ม `src_tx`
- ดอกเบี้ยจ่ายเงินกู้ภายในครอบครัว (ฝั่งผู้กู้) → หน้าต่างแก้ดอกเบี้ยที่รับของผู้ให้กู้ (ฝั่งผู้กู้เปลี่ยนตาม)
- แถว "รับชำระเงินให้กู้" (เงินต้น + ดอกเบี้ยรวมแถวเดียว) ในตารางเงินเข้า–ออก → กดที่แถวเปิดหน้าต่างเงินต้น + ดอกเบี้ย (`PairEdit` รองรับแบบกดที่แถว)
- `MOVE_SELECT` เพิ่ม `counter_fee, cash_holding_id` · หน้า Income & Expenses ใช้ `INC_SELECT` / `MOVE_SELECT` ชุดเดียวกับหน้าบัญชี · `loadKitCtx` โหลดรายได้ที่แถวอื่นอ้างถึงเพิ่ม (ปันผลในพอร์ตที่เข้าบัญชี · ดอกเบี้ยเงินกู้ภายใน)
