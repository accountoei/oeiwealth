## เปลี่ยนอะไร
- หน้าทรัพย์สิน › ตารางทรัพย์สิน: ปุ่ม **"แผนที่ดาวเทียม"** (ข้างปุ่มส่งออก KML) เปิด / ปิดแผนที่ภาพดาวเทียมของแปลงตามตัวกรอง (ประเภท / การใช้งาน / **กลุ่มทำเล** / สถานะ) · ซูมให้พอดีกับทุกแปลงที่เห็นอัตโนมัติ
- หมุดสีตามการใช้งาน (สีเดียวกับไฟล์ KML) + ป้ายชื่อพื้นเข้ม (เปิด / ปิดได้ที่ "แสดงชื่อ") · กดหมุด = ชื่อ กลุ่มทำเล ประเภท การใช้งาน เนื้อที่ + ลิงก์ "เปิดหน้าทรัพย์สิน" / Google Maps · ไม่แสดงมูลค่า
- `src/app/(app)/property/PropertyMap.tsx` (ใหม่) · `PropertyTable.tsx` (ปุ่ม + โหลดแผนที่แบบ `next/dynamic` เฉพาะตอนกดเปิด) · สไตล์หมุด / ป้ายใน `src/app/globals.css` · เพิ่มแพ็กเกจ `leaflet` 1.9.4 (+ `@types/leaflet`)

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| ภาพดาวเทียม | Sentinel-2 cloudless 2024 ของ EOX · ฟรีสำหรับใช้ที่ไม่ใช่เชิงพาณิชย์ (CC BY-NC-SA 4.0) ต้องแสดงที่มามุมล่างขวา · ความละเอียด ~10 ม. เหมาะดูภาพรวมทำเล ดูแปลงใกล้ ๆ ใช้ Google Maps จากหมุด |
| ความเร็ว | ไลบรารีแผนที่โหลดเฉพาะตอนกดเปิด ไม่ถ่วงการเปิดหน้าทรัพย์สิน |
| ข้อมูลที่แสดง | ไม่แสดงมูลค่า / ราคา (เหมือน KML · ภาพหน้าจออาจถูกส่งต่อ) |
