## เปลี่ยนอะไร
- `print/loan/[id]/contract.tsx`
  - เพิ่ม `LendAddendum`: บันทึกข้อตกลงต่อท้ายสัญญากู้ยืมเงิน (ให้กู้เพิ่ม ครั้งที่ N)
    - อ้างเลขที่และวันที่ของสัญญาเดิม
    - ข้อ 1 จำนวนที่ให้กู้เพิ่ม (รับเงินครบในวันทำบันทึก)
    - ข้อ 2 เงินต้นค้างชำระรวม ณ วันทำบันทึก
    - ข้อ 3 ดอกเบี้ย (อัตราปัจจุบัน)
    - ข้อ 4 การชำระคืนตามตารางแนบท้ายบันทึก
    - ข้อ 5 ผู้ค้ำยินยอมค้ำยอดที่เพิ่ม (ถ้ามีผู้ค้ำ)
    - ข้ออื่นใช้ตามสัญญาเดิม
    - ลายเซ็นผู้กู้ / ผู้ให้กู้ / ผู้ค้ำ / พยาน
    - อากรแสตมป์คิดจากยอดที่ให้กู้เพิ่ม
  - `repaymentText(d, "addendum")` ใช้ข้อความ "แนบท้ายบันทึกนี้"
  - `ScheduleAnnex` รับ `left` / `caption` / `sub` / `note` ได้
- `print/loan/[id]/page.tsx`
  - ดึงรายการจ่ายเงินกู้ (`LOAN_DISBURSEMENT`) มาสร้างหัวข้อ "บันทึกให้กู้เพิ่ม ครั้งที่ N" และ "ตารางผ่อนแนบท้ายบันทึก ครั้งที่ N" ทีละครั้ง
  - ใช้ตรรกะ "ให้กู้เพิ่ม" แบบเดียวกับหน้าสัญญา คือหลังวันยอดตั้งต้น และไม่นับการจ่ายครั้งแรกของสัญญาที่ให้กู้ในระบบ
  - `?lend=<id>` เลือกเฉพาะบันทึกครั้งนั้นกับตารางแนบท้ายให้
  - เงินต้นค้าง ณ วันทำบันทึก = ยอดตั้งต้น + เงินที่จ่ายให้กู้ถึงครั้งนี้ − เงินต้นที่รับคืนถึงวันนั้น
  - ตารางแนบท้ายบันทึก = งวดที่ครบหลังวันให้กู้เพิ่ม · ยอดคงเหลือเริ่มจากเงินต้นค้างนั้น
  - คำเตือนในแถบพิมพ์:
    - เงินต้นตามตารางหลังวันให้กู้เพิ่ม ไม่เท่ากับเงินต้นค้าง (ยังไม่ได้กด "คำนวณงวดที่เหลือใหม่")
    - สัญญาฉบับแรกพิมพ์จากตารางปัจจุบัน
  - ตารางแนบท้ายสัญญาฉบับแรก: ยอดคงเหลือไม่นับยอดให้กู้เพิ่มก่อนวันที่จ่ายจริง
  - ใบแจ้งยอดแสดงยอดให้กู้เพิ่ม
- `financial/loans/[id]` (`page.tsx`, `ScheduleTable.tsx`): แถวสีฟ้า "ให้กู้เพิ่ม" มีลิงก์ "พิมพ์บันทึกให้กู้เพิ่ม" (เปิดแท็บใหม่)

## การตัดสินใจที่ตกลงแล้ว
