## เปลี่ยนอะไร
- `split_lump`: บรรทัดฝั่งตรงข้ามของก้อน (`kind` = INCOME / EXPENSE ต่างจากก้อน · `move` = TRANSFER_IN / TRANSFER_OUT ทิศตรงข้าม) เพิ่มยอดที่ต้องแยก — ก้อนรายได้ 10,000 = รายได้ 12,000 หักค่าใช้จ่าย 2,000 · ลงฝั่งตรงข้ามก่อน (ระบบคำนวณก้อนใหม่ = ก้อนโตขึ้น) แล้วค่อยแยกฝั่งเดียวกับก้อน
  - ได้เฉพาะก้อนของบัญชีธนาคาร (4 แบบ) และก้อนของบัตร (รายได้ / ค่าใช้จ่าย) · ก้อนของหนี้ไม่ได้ (รายได้ลดหนี้ต้องแยกมาจากก้อนของหนี้)
  - รายได้ / ค่าใช้จ่ายฝั่งตรงข้ามทำได้แม้ปิดงวดแล้ว (เหมือนการแยกเดิม) · เงินโอนต้องเปิดงวด
  - `move` แบบเดิม (TRANSFER / CARD_PAYMENT / LIABILITY_PAYMENT / PAY_FROM) ยังรับได้ (หน้าหนี้สิน / บัตรยังใช้)
- `SplitForm` แบบ `sides` (หน้า Income & Expenses + หน้าบัญชีธนาคาร): แต่ละบรรทัดเลือก รายได้ · ค่าใช้จ่าย · โอนเข้าบัญชี · โอนออกบัญชี · ค่าเริ่มต้น = ฝั่งของก้อน · ยอด "แยกแล้ว" = ฝั่งเดียวกัน − ฝั่งตรงข้าม
  - จ่ายบัตร / จ่ายหนี้ / จ่ายจากบัญชี เอาออกจากหน้านี้ → บันทึกที่หน้าบัตร / หนี้สิน (ก้อนของบัญชีปรับเอง) · หน้าหนี้สิน / บัตรยังแยกแบบเดิมได้
