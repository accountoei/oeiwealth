## เปลี่ยนอะไร
- กล่องแรกของทุกหน้า = มูลค่า "(THB Equivalent) · ถึงวันนี้" + ▲/▼ % จากสิ้นเดือนก่อน (ชุดเดียวกับ Investments / Dashboard: `month_family_items` / `month_person_items` กลุ่ม ALTERNATIVE / BUSINESS / LOANS) + จำนวนรายการ

- Alternative: มูลค่ารวม (N รายการ · ทองราคาอัตโนมัติ) · กำไร / ขาดทุนที่ยังไม่ขาย (มูลค่า − ราคาทุน, %) · ผลตอบแทนที่รับแล้วปีนี้ ม.ค. → เดือนที่เลือก + ของเดือน · อัปเดตมูลค่าเก่าสุด + จำนวนเกิน 90 วัน (แดง)
- Business: มูลค่าธุรกิจรวม (N กิจการ · ประเมินล่าสุด) · มูลค่าเทียบเงินลงทุน · เงินปันผลรับปีนี้ + ของเดือน + % ของเงินลงทุน · ประเมินมูลค่าเก่าสุด + จำนวนเกิน 1 ปี (แดง)
- Loans: เงินต้นคงเหลือรวม (= รวมในความมั่งคั่งสุทธิ · สัญญาที่เปิด / ปิดแล้ว) · รับชำระของเดือน (เงินต้น · ดอกเบี้ย · ถึงกำหนดเดือนนี้ + % งวดที่รับแล้ว) · ดอกเบี้ยรับปีนี้ + อัตราเฉลี่ยถ่วงตามเงินต้นคงเหลือ · ค้างชำระ (แดง · N งวด · K สัญญา · เสี่ยงไม่ได้คืน) / ✓ ไม่มีงวดค้าง
- กล่องสัดส่วนของ Alternative / Business เอาบรรทัด "รวม …" ออก (มีในกล่องแรกแล้ว) · ตารางสถานะของ Loans คงแถวรวม (บอกว่าตัดหนี้สูญ = 0)
- ทุกตัวเลขตามสมาชิกที่เลือก (× สัดส่วนเจ้าของ) · "ปีนี้" = ม.ค. ถึงเดือนที่เลือกด้านบน
