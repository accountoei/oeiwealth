## เปลี่ยนอะไร
1. `ScheduleTable.tsx`: แถวรวมรายการจริงขึ้นว่า "รับชำระ N ครั้ง · ให้กู้เพิ่ม M ครั้ง" แทน "รับจริง N ครั้ง"
2. `ScheduleTable.tsx`: ตารางกำหนดความกว้างคอลัมน์เอง (`table-fixed`)
   - ช่องวันที่ / รายการ 22%
   - คอลัมน์ตัวเลขกว้างเท่ากันทุกช่อง
   - สถานะ 13rem
   - ตัวเลขไม่ตัดบรรทัด · จอแคบเลื่อนซ้าย–ขวาได้ (`min-w-[66rem]`)
3. คำว่า "ผ่อนผันหลังครบกำหนดงวด" เปลี่ยนเป็น "ชำระล่าช้าไม่เกิน" ในช่องกรอก หน้ารายละเอียด และข้อความผิดพลาด · บรรทัดสรุปบนตารางเปลี่ยนจาก "ผ่อนผันถึง" เป็น "ชำระได้ถึง"
4. กล่องสถานะการชำระเงินต้น: ต่อท้าย "ก่อน Go-live X (ตามตารางผ่อน ไม่ได้บันทึกเป็นรายได้ในระบบ)"
   - X = ดอกเบี้ยของงวดที่ครบถึงวันยอดตั้งต้น
5. ปุ่ม "แก้ตารางผ่อนทั้งชุด" ย้ายไปกล่องรายละเอียด หน้าปุ่ม "แก้ไขข้อมูล"
   - ขนาดเล็กเท่ากัน (`ScheduleEditor small`)
   - ขึ้นเฉพาะก่อนมีการรับชำระ ตามเงื่อนไขเดิม
   - ยังไม่มีตาราง: ปุ่ม "+ ตั้งตารางผ่อน" อยู่ที่กล่องตารางผ่อน
6. หัวกล่องตารางผ่อน: ชื่อชิดซ้าย · ปุ่ม "+ ตั้งตารางผ่อน" / "คำนวณงวดที่เหลือใหม่" และ "บันทึกรับชำระ" เรียงกันชิดขวา · บรรทัดสรุปและคำเตือนลงไปบรรทัดถัดไป
7. แท็บบันทึก: ช่องวันที่ย้ายไปมุมขวา คำอธิบายอยู่ซ้าย แบบเดียวกับแท็บบันทึกรับของ Investments และค่าเช่า
   - มีผลกับ `LoanBatch`, `InsuranceBatch` (จ่ายเบี้ย / รับผลประโยชน์), `liabilities/PayBatch` และ `property/ExpenseBatch`

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| คำเรียกวันผ่อนผัน | "ชำระล่าช้าไม่เกิน (วัน)" · สรุปบนตาราง "ชำระได้ถึง …" |
| ตำแหน่งปุ่มตารางผ่อน | ยังไม่มีตาราง = "+ ตั้งตารางผ่อน" มุมขวาบนกล่องตาราง · มีแล้ว = "คำนวณงวดที่เหลือใหม่" ตรงนั้น + "แก้ตารางผ่อนทั้งชุด" ในกล่องรายละเอียด (ก่อนมีรับชำระ) |
| วันที่ในแท็บบันทึก | มุมขวาทุกเมนู |
