- วันที่: 6 พ.ย. 2026 · branch `claude/popup-sizes`
- SQL: ไม่มี SQL
- ทดสอบ: tsc / eslint (35 warnings เท่าเดิม) / next build ผ่าน · ตรวจภาพ popup ขนาดเล็กด้วย Playwright (หน้าจอ 1280 / 820 / 390 ใช้ CSS จริงของแอป) ไม่เบียด ไม่ล้นกรอบ

## เปลี่ยนอะไร
- `Modal` มี 3 ขนาด: `sm` 448 px · `md` 768 px (ค่าเริ่มต้น) · `lg` 1,152 px (เดิมมีแค่ 768 / 1,152) · type `ModalSize` ใช้ร่วมกับ `ModalButton` / `useActionSlot` / `useRowPanel`
- นับ popup ทั้งแอป 171 จุด แล้วปรับให้ตรงกติกา:
  - → เล็ก: หน้าต่างถามยืนยัน (`ConfirmDialog`) · ลบ / เปลี่ยนสถานะ (`DeleteEntity`, `useStatusDelete`) · เลือกตัวอักษร · เปลี่ยนชื่อหมวด · ดูเลขบัญชีเต็ม · ภาษี: ยื่นเพิ่มเติม / ลบแบบ / ผลการชำระ · ปิดเดือน / ยกเลิกการปิดเดือน · ยกเลิก / เปลี่ยน / ยืนยัน Go-live · แหล่งอัตราแลกเปลี่ยน · เลิกสัญญาเช่า · รับค่าน้ำไฟ · เพิ่มความคุ้มครอง · เพิ่มมูลค่าเวนคืน · แก้ไขครอบครัว · คัดลอกห้อง
  - ใหญ่ → กลาง: เพิ่มเงินบริจาค · กรอกรายละเอียดบริจาค · จ่ายเงินกองทุนสำรองเลี้ยงชีพ · อัปเดตมูลค่าเวนคืน · อัปโหลดเอกสาร (เป็นฟอร์ม 1 รายการ ไม่ใช่ตาราง)
  - กลาง → ใหญ่: ผลตรวจสุขภาพ (ตารางกรอกหลายแถว) · แก้ไขรายละเอียดสมาชิก (~30 ช่อง) · สัญญาเช่าใหม่ · วางตารางมูลค่าเวนคืน (มีตารางตัวอย่าง)
  - ปุ่มแก้ไขแถวในตาราง (`RowActions`) เลือกขนาดเอง: ช่องแก้ไข 1–3 ช่อง หรือมีแต่ลบ = เล็ก เรียงลงคอลัมน์เดียว · มากกว่านั้น / ฟอร์มของหน้าเอง / มีส่วนเพิ่ม = กลาง
- ช่องเลือกบัญชีในฟอร์มรับค่าน้ำไฟ ไม่ล้นกรอบบนมือถือ (`max-w-full`)
- กติกาเขียนไว้ใน `AGENTS.md` (หัวข้อ Buttons vs row click vs links) และหัวไฟล์ `Modal.tsx`
