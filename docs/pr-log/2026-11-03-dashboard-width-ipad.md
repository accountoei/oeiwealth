## เปลี่ยนอะไร
เจ้าของเปิดบนจอ 15 นิ้ว (175%) และ 17 นิ้ว (125%) แล้วเห็นที่ว่างในกล่องมาก จึงเลือกข้อ 2 + 3 + 4 + ข. + ค. และให้แก้จุดที่พบระหว่างตรวจด้วย

- **ข้อ 2 · ความกว้างเนื้อหาสูงสุด 1,440** (`src/app/(app)/layout.tsx` · ทุกหน้า): เดิม 1,280 เมื่อหน้าต่างแคบกว่า 1,536 และ 1,600 เมื่อกว้างกว่านั้น · ตอนนี้ใช้ 1,440 ค่าเดียว (เนื้อหา 1,376 + ขอบ) → จอ 17 นิ้ว / จอคอม 24 นิ้ว ดูใกล้เคียงจอ 15 นิ้ว
- **ข้อ 3 · กล่องในแถวเดียวกันสูงพอดีกัน**:
  - กราฟยืดเต็มกล่อง (`TrendChart.tsx`: ความสูงต่ำสุดตามความสูงจอแบบเดิม แล้วยืดตามกล่อง)
  - แถวในกล่องสัดส่วนกระจายลงจนขอบล่างตรงกับกล่องรายบุคคล
  - บรรทัด "รวมครอบครัว" อยู่ล่างสุดของกล่องรายบุคคล
- **ข้อ 4 · การ์ดบนแบ่งซ้าย–ขวา**: เมื่อเนื้อในการ์ด ≥ 24rem ตัวเลขอยู่ซ้าย แถวข้อมูล (สภาพคล่อง / ระดับหนี้ / % หลายช่วง) อยู่ขวา → การ์ดสูง 206 → 156px · การ์ดแคบยังเป็นแบบเดิม
- **ข. · Dashboard จัดคอลัมน์ตามความกว้างเนื้อหาจริง** (`@container/dash`, หักเมนูซ้ายแล้ว · เดิมดูขนาดหน้าต่าง):
  - การ์ดบน 3 ใบเรียงกันเมื่อเนื้อหา ≥ 56rem
  - กราฟ + "เปลี่ยนเพราะอะไร" และสัดส่วน + รายบุคคล วางคู่กันเมื่อเนื้อหา ≥ 58rem · แคบกว่าเรียงลงเต็มความกว้าง (เดิม iPad Pro แนวตั้งกล่องขวาเหลือ 227px ตัวหนังสือตกบรรทัด ชื่อคนถูกตัด)
  - กล่องสัดส่วน 2 คอลัมน์เมื่อกล่อง ≥ 40rem · 30–40rem แถวเดียวแบบ ชื่อ | แถบ | % | ยอด
  - ในการ์ด: ชื่อเต็ม + ชื่อคนเมื่อการ์ด ≥ 15rem · ป้ายยอดเปลี่ยนเป็นบาท + % เมื่อ ≥ 20rem (แคบกว่า = % อย่างเดียว)
- **ค. · iPad ยุบแถบเมนูซ้ายเอง** (`Sidebar.tsx`):
  - จอสัมผัสที่ไม่มีเมาส์ และกว้าง ≥ 768px → ยุบเหลือไอคอน (เนื้อหากว้างขึ้น 192px)
  - กดขยายได้และจำไว้ที่เครื่องนั้น · cookie `fwv_nav_collapsed`: `1` ยุบ · `0` ขยาย (เลือกเอง) · ไม่มี = ยังไม่เคยเลือก
- **แก้จุดจาก #299**: จอ 1,280 (เมนูกว้างปกติ) บรรทัดล่างของการ์ด เช่น "ค่างวด 85,000 บาท/เดือน" และ "ณ วันนี้ · หลังหักหนี้สินแล้ว" ถูกตัดเป็น … → การ์ดแคบ (< 20rem) ซ่อน "จากสิ้นเดือน…" (ป้ายด้านบนชี้แล้วยังเห็นฐานเทียบ)
