## เปลี่ยนอะไร
- **ค่าเช่าตามรอบวันจ่าย** (`private.lease_cycles` · ใช้ทั้ง `v_expected_income` และ `lease_rent_schedule`)
  - รอบนับจากวันจ่าย (`payment_due_day` · ว่าง = วันที่ของวันเริ่มสัญญา) · วันจ่ายตรงวันเริ่มสัญญา = ทุกงวดเต็ม
  - วันจ่ายไม่ตรง → งวดแรก = วันเริ่มสัญญาถึงก่อนวันจ่ายของเดือนถัดไป คิดตามจำนวนวัน (เช่น เริ่ม 16 ต.ค. จ่ายวันที่ 5 → 16 ต.ค.–4 พ.ย. 20 วัน · เริ่ม 1 ก.ย. จ่ายวันที่ 5 → 1 ก.ย.–4 ต.ค. = 1 รอบ + 4 วัน)
  - งวดแรกครบกำหนดภายใน 5 วันนับจากวันเริ่มสัญญา · งวดต่อไปจ่ายล่วงหน้าในวันจ่าย
  - งวดสุดท้าย (ครบสัญญา / เลิกสัญญากลางรอบ) คิดถึงวันสุดท้ายตามจำนวนวัน · รวมทั้งสัญญายังเท่าจำนวนเดือนเต็ม
  - 1 งวดต่อเดือนเหมือนเดิม (`income_period` = เดือนที่รอบเริ่ม) → หน้ารับค่าเช่า / รายรับรายจ่าย / ปิดเดือนใช้ได้ไม่ต้องแก้
  - `v_expected_income` / `v_lease_rent_tracking` เพิ่ม `cycle_start`, `cycle_end` ท้ายตาราง
- **วิธีคิดวันเศษ** `property_leases.prorate_basis`: `ACTUAL` (÷ จำนวนวันจริงของรอบ · ค่าเริ่มต้น) / `DAYS30` (÷ 30 ไม่เกินค่าเช่าเต็มรอบ) · เลือกในฟอร์มสัญญา + ปุ่มแก้ไขสัญญา · ต่อสัญญาใช้ค่าเดิม
- ฟอร์มสัญญาแสดงตัวอย่างงวดแรก (ช่วงวัน · จำนวนวัน · ยอด · วันครบกำหนด) ตามวันเริ่ม / วันจ่าย / วิธีคิดวันเศษ (`firstRentCycle` ใน `lib/lease.ts`)
- **กันสัญญาทับกัน** (trigger `t55_overlap`): ทรัพย์สินเดียวกัน + ช่วงวันทับ + (ห้องเดียวกัน หรือฉบับใดไม่ระบุห้อง = เช่าทั้งหลัง) → บันทึกไม่ได้ บอกสัญญาที่ทับและวันจบ · ผู้เช่าคนเดียวกันเช่า 2 ห้องพร้อมกันยังทำได้ · แก้แบบไม่ขยายวัน / ไม่เปลี่ยนห้อง (เลิกสัญญา · แก้ค่าเช่า) ไม่ถูกตรวจ
- **สัญญาใหม่ไม่ยกเงินประกัน**: ช่อง "ต่อสัญญา: ยกเงินประกัน" แสดงเฉพาะเมื่อเลือก "ต่อจากสัญญาเดิม" และยกจากฉบับนั้นเท่านั้น (เดิมติ๊กให้เองแม้เลือกสัญญาใหม่)
- งวดที่ไม่เต็มรอบแสดงช่วงวันใต้ยอด (แท็บรับค่าเช่า + หน้าทรัพย์สิน) · งวดที่รับมากกว่ายอดที่ควรได้ แสดง "รับเกิน …"
- สัญญาที่พิมพ์: ตารางค่าเช่าแนบท้ายใช้ `lease_rent_schedule` (เพิ่มคอลัมน์ "รอบค่าเช่า") · ข้อค่าเช่าระบุงวดแรกที่คิดตามวัน กำหนดชำระงวดแรก 5 วัน และการคิดตามวัน + คืนค่าเช่าล่วงหน้าเมื่อสิ้นสุด / เลิกกลางรอบ

## การตัดสินใจที่ตกลงแล้ว
| เรื่อง | ตกลง |
|---|---|
| วันเริ่มคิดค่าเช่า | "วันเริ่มสัญญา" = วันทำสัญญา = วันเข้าอยู่ (ระบบไม่มีช่องวันทำสัญญาแยก) |
| รอบค่าเช่า | นับจากวันจ่าย · ไม่ตรงวันเริ่ม → งวดแรกคิดตามวันถึงก่อนวันจ่ายเดือนถัดไป |
| ครบกำหนดงวดแรก | ภายใน 5 วันนับจากวันเริ่มสัญญา |
| วันเศษ | เลือกได้ต่อสัญญา: วันจริงของรอบ (ค่าเริ่มต้น) / หาร 30 |
| สัญญาทับ | ห้องเดียวกัน หรือฉบับใดไม่ระบุห้อง → ห้ามทับ |
| ยกเงินประกัน | เฉพาะตอนต่อสัญญาจากฉบับที่เลือก |
