## เปลี่ยนอะไร
- **ปุ่ม "ผู้เช่าออก / คืนเงินประกัน"** บนการ์ดสัญญา (ADMIN / EDITOR) → หน้าต่างเดียว (`CloseLeaseForm.tsx`)
  - เลือกวันที่ผู้เช่าออก (วันสุดท้ายที่คิดค่าเช่า) + วันที่คืนเงิน · สัญญาที่เลิกไว้แล้ว ใช้วันเลิกสัญญา (แก้ไม่ได้ในหน้าต่างนี้)
  - ระบบคิดค่าเช่าถึงวันที่ออกด้วยสูตรเดียวกับหน้ารับค่าเช่า (`private.lease_cycles` · งวดสุดท้ายคิดตามวัน) → `lease_closeout_preview`
  - เงินประกัน − ค่าเช่าค้าง − ค่าน้ำไฟเรียกเก็บที่ยังไม่ได้รับ − ค่าเสียหาย (เติมจากรายการส่งมอบ · แก้ได้) − ริบเงินประกัน = **คืนเงินประกัน** · + ค่าเช่าที่จ่ายล่วงหน้าเกินวันที่อยู่จริง = **โอนคืนผู้เช่ารวม** (โอนครั้งเดียวจากบัญชีที่เลือก)
  - ยอดหักเกินเงินประกัน → บันทึกไม่ได้ (ให้รับค่าเช่า / ค่าน้ำไฟที่ค้างก่อน หรือลดยอดหัก)
- **บันทึกครั้งเดียวทั้งชุด** (`close_lease` · ADMIN / EDITOR)
  - ออกก่อนวันสิ้นสุดสัญญา → เลิกสัญญาให้ ณ วันที่ออก
  - ค่าเช่าค้างแต่ละงวด → รายรับค่าเช่า "ได้รับแล้ว" ของงวดนั้น (หักจากเงินประกัน ไม่ผ่านบัญชี)
  - ค่าน้ำไฟที่ค้าง → รายรับเรียกเก็บ + ค่าน้ำไฟขึ้น "ได้รับแล้ว"
  - ค่าเสียหาย / ริบเงินประกัน → รายได้อื่น "หักจากเงินประกัน: …"
  - เงินประกันที่เหลือ → รายการเงินออก "คืนเงินประกัน" จากบัญชี · สถานะเงินประกัน = คืนแล้ว
  - ค่าเช่าล่วงหน้าที่คืน → ค่าใช้จ่ายของทรัพย์สิน "คืนค่าเช่าล่วงหน้า" จ่ายจากบัญชีเดียวกัน (รายรับติดลบไม่ได้)
  - เก็บสรุปไว้ในตาราง `lease_closeouts` (อ่านได้ทุกบทบาท · เขียนผ่านฟังก์ชันเท่านั้น)
- **ปุ่ม "ยกเลิกผู้เช่าออก"** (`undo_close_lease` · ADMIN / EDITOR) → ลบรายการทั้งชุด · เงินประกันกลับเป็น "ถืออยู่" · ถ้าระบบเป็นคนเลิกสัญญา คืนสถานะสัญญาให้ด้วย
  - รายการที่มาจากการบันทึกผู้เช่าออก แก้ / ลบทีละรายการไม่ได้ (trigger `t15_closeout_lock`) · ปุ่ม "ยกเลิกการคืนเงินประกัน" เดิมไม่ใช้กับสัญญาที่บันทึกผู้เช่าออก
- **พิมพ์ "บันทึกการส่งคืนทรัพย์สินที่เช่าและการคืนเงินประกัน"** จากการ์ดสัญญา (`/print/lease/<id>?s=closeout`) · รายการหัก / คืน ยอดเป็นตัวอักษร ช่องลงชื่อ
- **ปุ่ม "ต่อสัญญา"** บนการ์ดสัญญา → ฟอร์มสัญญาใหม่ที่เลือก "ต่อจากสัญญาเดิม" ไว้ให้ (ยกเงินประกันจากฉบับนี้) · แสดงเมื่อยังไม่มีสัญญาถัดไปในห้องเดียวกัน
- **ADMIN แก้ / ยกเลิกวันเลิกสัญญา** (ปุ่ม "แก้วันเลิกสัญญา") · trigger `t45_termination`: แก้วันที่เลิกไว้แล้วได้เฉพาะ ADMIN · แก้ไม่ได้หลังบันทึกผู้เช่าออก หรือคืนเงินประกันแล้ว (ต้องยกเลิกก่อน)
- ปุ่ม "คืนเงินประกัน" เดิม (`SettleDepositForm`) เหลือเฉพาะกรณีเงินประกันคนละสกุลเงินกับค่าเช่า
