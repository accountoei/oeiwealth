## เปลี่ยนอะไร
- ประกันทรัพย์สิน (บ้าน / รถ) มีปุ่มหัวข้อที่ตั้งชื่อไว้ให้ 4 ปุ่ม + "อื่น ๆ" (`PROPERTY_COVERAGES` ใน `src/lib/format.ts`)
  - ทรัพย์สินเสียหาย / สูญหาย · ความรับผิดต่อบุคคลภายนอก · ค่าที่พักชั่วคราว (สูงสุด N วัน) · ความรับผิดส่วนแรก (ทรัพย์สิน)
  - แต่ละปุ่ม = แถว "อื่น ๆ" ที่ใส่ชื่อไว้แล้ว (แก้ชื่อได้) · ช่องหมายเหตุมีตัวอย่าง · ใส่แล้วปุ่มนั้นหาย
  - กดปุ่มแล้วยังไม่ใส่วงเงิน = แถวว่าง ไม่เตือน ไม่บันทึก
- ความรับผิดส่วนแรกของทรัพย์สิน **ไม่ใช่** หัวข้อ "ความรับผิดส่วนแรก (Deductible)" ของหมวดสุขภาพ → ไม่ปนกัน และไม่ทำให้ใครนับว่า "มีประกันสุขภาพ"
- ประกันทรัพย์สินไม่มีปุ่ม "แสดงทุกหัวข้อ" (หัวข้อของคน เช่น ค่ารักษา ไม่เกี่ยว) ทั้งฟอร์มเพิ่มกรมธรรม์และหน้าต่างแก้ความคุ้มครอง
- "สูงสุด" ใช้หน่วยตามหัวข้อ (`covCountUnit`): ค่าที่พักชั่วคราว = วัน · ความเสียหาย / บุคคลภายนอก / ส่วนแรก = เลือกได้แค่รอบ (ต่อครั้ง / ต่อปี / ตลอดสัญญา)
- ประกันทรัพย์สินไม่ผูกกับคน จึงไม่ขึ้นในแท็บความคุ้มครอง / หน้าพิมพ์สำหรับโรงพยาบาลอยู่แล้ว · แสดงที่หน้ากรมธรรม์
