## เปลี่ยนอะไร
- **หน้ากรมธรรม์ (`insurance/[id]`)**: แท็บ "รับผลประโยชน์" + "ชำระเบี้ย" รวมเป็นแท็บเดียว "เบี้ยและผลประโยชน์" (ประกันทรัพย์สิน = "ชำระเบี้ย") · ลิงก์เดิม `?tab=premium` / `?tab=benefit` เปิดแท็บนี้ · ลิงก์ "กรมธรรม์ →" ในหน้าทรัพย์สินเปลี่ยนเป็น `?tab=flow`
- **ตารางเดียว** (`insurance/[id]/FlowTable.tsx`): งวดเบี้ย + งวดผลประโยชน์เรียงตามวันครบกำหนด (วันเดียวกัน เบี้ยก่อน) · คอลัมน์ จ่ายเบี้ย / รับผลประโยชน์ แยกกัน · เงินที่จ่าย / รับจริงแทรกใต้งวดนั้น (แทนตารางประวัติจ่ายเบี้ย / ประวัติรับผลประโยชน์ · ปุ่มแก้ / ลบการจ่าย และ "ยกเลิกทั้งก้อน" อยู่ที่แถวนั้น กติกาเดิม) · รับเงินก้อนไม่ผูกงวด (ครบสัญญา / เวนคืน / สินไหม) เป็นแถวของตัวเองตามวันที่รับ · ตัวกรอง ทั้งหมด / เบี้ย / ผลประโยชน์ · ตารางสูงสุด 40rem เลื่อนไปงวดแรกที่ค้างตอนเปิดแท็บ
- **สุทธิสะสม** (ผลประโยชน์ − เบี้ย นับรวมถึงแถวนั้น): งวดที่จ่าย / รับแล้วใช้ยอดจริง · ก่อน Go-live ใช้เต็มงวด · งวดค้างใช้ยอดตามตาราง (ตัวจาง = คาดการณ์) · ป้าย "คุ้มทุน" = แถวแรกที่ยอดกลับมาไม่ติดลบและไม่ติดลบอีกจนจบตาราง · แสดงเฉพาะกรมธรรม์ที่มีผลประโยชน์
- **หัวตาราง**: จ่ายเบี้ยแล้ว · รับผลประโยชน์แล้ว · สุทธิถึงวันนี้ · จุดคุ้มทุน (หรือ "ไม่ถึงตามตาราง · ขาด …") · ยอดตามตารางทั้งหมด · ปุ่มตั้งตารางเบี้ย / ตารางผลประโยชน์อยู่มุมขวาบนคู่กัน
- **IRR 3 ตัว** (XIRR ตามวันที่จริง · วัน ÷ 365 · ไม่รวมภาษีที่ลดหย่อนได้): ตามสัญญา (ทุกงวด ยอดเต็ม ณ วันครบกำหนด) · คาดการณ์ (เงินจริง + ยอดค้างตามตาราง · งวดเลยกำหนดคิด ณ วันนี้ · กรมธรรม์จบแล้ว = "จริง") · ถ้าเวนคืนวันนี้ (เงินจริง + มูลค่าเวนคืนล่าสุด ณ วันนี้ · เฉพาะกรมธรรม์ที่มีผลและมีมูลค่าเวนคืน) · คำนวณไม่ได้ = "–" พร้อมเหตุผล · หลายสกุลเงิน = ไม่คำนวณ
- ฟังก์ชันคำนวณ: `src/lib/insurance-flow.ts` (`xirr`, `runningNet`, `contractFlows`, `projectedFlows`, `surrenderFlows`) · ชุดทดสอบ `scripts/insurance-flow.test.mjs` (เพิ่มในคำสั่งทดสอบของ AGENTS.md)
