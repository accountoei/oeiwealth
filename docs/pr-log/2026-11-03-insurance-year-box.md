## เปลี่ยนอะไร
- **ภาพรวม → "กรมธรรม์ทั้งหมด"**: ใต้ชื่อแสดงระยะสัญญา "เริ่ม – สิ้นสุด" · แยกคอลัมน์ "เบี้ยงวดถัดไป" (วันที่ · ยอด · เลยกำหนด · จ่ายถึงปี / เหลือกี่งวด) กับ "ผลประโยชน์งวดถัดไป" (วันที่ · ยอด · รับถึงปี / เหลือกี่งวด)
- เอากล่อง "กรมธรรม์ที่มีผล" ออกจากแท็บรับและแท็บจ่าย (ข้อมูลอยู่ในตารางภาพรวมแล้ว)
- **แท็บบันทึกรับผลประโยชน์ / จ่ายชำระเบี้ยประกัน** (`insurance/InsuranceBatch.tsx` เขียนใหม่ · ลบ `YearTable.tsx`):
  - การ์ด 3 ใบ: ครบกำหนดเดือนที่เลือก · รับแล้ว / จ่ายแล้วเดือนที่เลือก (ตามวันที่จริง) · ค้างรับ / ค้างจ่าย (เลยกำหนด ณ วันนี้)
  - กล่องเดียว "ผลประโยชน์ ปี …" / "เบี้ยประกัน ปี …" แทน 3 กล่องเดิม (งวดที่ยังไม่ได้รับ / ที่รับแล้วเดือนนี้ / ตารางทั้งปี): กรมธรรม์ละกลุ่ม · งวดในปี + ป้ายสถานะ · ยอดงวด · รับ / จ่ายแล้ว (กดแก้ / ยกเลิกในแถว) · คงเหลือ · ช่องกรอกยอด + บัญชีเฉพาะงวดที่ถึงกำหนด (ค้าง หรือภายใน 60 วัน) · ติ๊ก "เปิดช่องกรอกงวดที่ยังไม่ถึงกำหนด" เพื่อบันทึกล่วงหน้า
  - ปีนี้รวมงวดค้างจากปีก่อน (ป้ายแดง) และงวดปีหน้าที่ครบภายใน 60 วัน · ยอดรวมท้ายกล่องนับเฉพาะงวดในปีนั้น
  - รับเงินก้อนที่ไม่ผูกงวด (ครบสัญญา / เวนคืน / สินไหม) แสดงใต้ชื่อกรมธรรม์ · ยกเลิกที่หน้ากรมธรรม์
  - กรมธรรม์ที่มีหลายงวดในปี (รายเดือน / ไตรมาส) ย่องวดที่จบแล้วเป็นบรรทัดเดียว กด "ดู / แก้ทีละงวด" เพื่อกาง
  - เลือกปีด้วย dropdown (`src/components/YearSelect.tsx` · แบบกล่องภาษีที่ดินและสิ่งปลูกสร้าง): ปีแรก–ปีสุดท้ายที่มีงวด · ✓ = มีงวด · "· ค้าง" = มีงวดเลยกำหนด
- ข้อมูลหน้า: ยอดที่บันทึกแล้วของงวดในกล่องดึงต่อจากคำสั่งงวด (`.then`) ในรอบเดียวกัน · เหลือ 1 รอบ (เดิม 3 รอบ) · `INS_OPEN` ย้ายไป `src/lib/format.ts`
