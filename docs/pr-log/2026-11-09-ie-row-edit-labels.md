## เปลี่ยนอะไร
- ตารางเงินเข้า–ออก (แท็บภาพรวม + หน้ารายละเอียดบัญชีธนาคาร · ชุดคำสั่งกลาง `entry-kit.tsx`) กดแถวแล้วเปิดฟอร์มเดียวกับหน้าต้นทางเพิ่ม:
  - รับเงินประกัน (ถอนมูลค่าเวนคืน `ASSET_SALE` + ผลประโยชน์ส่วนที่เป็นรายได้) → `ReceiptEdit` ของหน้ากรมธรรม์ · เฉพาะรายการรับล่าสุดของกรมธรรม์ + ADMIN / EDITOR (เหมือนหน้ากรมธรรม์)
  - ซื้อทรัพย์สิน: Property = `PropertyPaymentForm` (เลือกแถวส่วนประกอบ) · Alternative = วันที่ / ยอด / รายละเอียด · กิจการ = วันที่ / ยอด
  - ขายทรัพย์สิน (Property / Alternative) = ลบได้อย่างเดียว (เหมือน `AssetTradeHistory`) · ขายบางส่วน / ซื้อขายหุ้นกิจการ = ลิงก์
  - รับคืนเงินต้นอย่างเดียว (ไม่มีดอกเบี้ยคู่) = วันที่ / เงินต้น (เหมือนหน้า Loans)
  - ซื้อ / ขาย / ไถ่ถอนในพอร์ตที่ตัด / เข้าบัญชีตรง = ช่องเดียวกับหน้าพอร์ต (`portfolioTxFields` ใน `src/lib/source-edit.ts` ใช้ร่วมกับหน้าพอร์ต)
  - ฝั่งผู้กู้ของเงินกู้ภายในครอบครัว = แก้รายการฝั่งผู้ให้กู้ (ให้กู้ / รับชำระ)
  - เบี้ยประกันจ่ายทั้งเล่ม (แถวรวม) = กดยอดของแต่ละส่วนเพื่อแก้ / ลบส่วนนั้น (แบบหน้ากรมธรรม์)
- แถวที่แก้ตรงไม่ได้ → ชื่อรายการเป็นลิงก์ไปหน้าต้นทาง: ซื้อ / ขายทรัพย์สิน, ถอนมูลค่าเวนคืน (หน้ากรมธรรม์), รับคืนเงินต้น / ให้กู้ (หน้าเงินให้กู้), เงินประกันการเช่า (หน้า Property ของสัญญา)
- ป้ายตามเมนูต้นทาง (`sourceMeta` ใน `src/lib/ledger.ts`): ซื้อ / ขาย Property · ซื้อ / ขาย Alternative · ลงทุนเพิ่มในกิจการ / ขายหุ้นกิจการ · เงินประกัน (หมวด "ประกัน (ถอนมูลค่าเวนคืน)") · ซื้อหลักทรัพย์ / ขาย-ไถ่ถอนหลักทรัพย์ · รับ / ชำระเงินกู้ภายใน · รับ / คืนเงินประกันการเช่า
- ข้อมูลเพิ่ม (รายการรับเงินประกัน · แถวของ Property · รายการในพอร์ต) โหลดใน `income-expenses/kit-extras.ts` (ต่อจากคำถามรายการเดือนใน `page-data.ts` · หน้าบัญชีใน `entry-kit-load.ts`)
