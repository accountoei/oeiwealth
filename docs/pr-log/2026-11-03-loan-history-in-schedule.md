## เปลี่ยนอะไร
- `financial/loans/[id]/ScheduleTable.tsx`: รับ `events` (รายการเงินจริง) แล้วแทรกในตารางผ่อนตามวันที่ (วันเดียวกัน: งวดก่อน แล้วรายการจริง)
  - แถวสีเขียว "รับ": รับชำระ / รับคืนเงินต้น / ดอกเบี้ยรับ · ช่อง "รวม" = เงินเข้าบัญชีจริง (เงินต้น + ดอกเบี้ย − ภาษีหัก ณ ที่จ่าย) ตรงกับ Statement
  - แถวสีฟ้า "ให้กู้": ให้กู้เพิ่ม (ยอดในคอลัมน์ "ให้กู้เพิ่ม") / จ่ายเงินกู้ครั้งแรกของสัญญา (ยอดในช่อง "รวม") · แสดงยอดคงเหลือหลังให้กู้
  - แสดงเฉพาะแท็บ "ชำระแล้ว" / "ทั้งหมด" · แท็บ "ยังไม่ชำระ" มีข้อความบอกว่าดูได้ที่ไหน
  - หัวคอลัมน์ "เงินต้น" → "คืนเงินต้น" · คอลัมน์ "ให้กู้เพิ่ม" แสดงเฉพาะสัญญาที่เคยให้กู้เพิ่ม
  - ท้ายตาราง: แถว "รับจริง N ครั้ง" รวมเงินต้น / ให้กู้เพิ่ม / ดอกเบี้ย / เงินเข้าบัญชี
  - สัญญาที่ยังไม่มีตารางผ่อน: แสดงเฉพาะรายการจริง (ไม่มีปุ่มแท็บ)
- `financial/loans/[id]/page.tsx`:
  - สร้าง `events` จากรายการเดิมของกล่องประวัติ (เงินต้น + ดอกเบี้ยที่รับครั้งเดียวกันรวมเป็น 1 แถวด้วย `movement_group_id`)
  - ปุ่มแก้ / ลบ (`RowActions` แบบปุ่ม, `UndoButton` PAYMENT ลบทั้งการรับชำระ) มีเฉพาะรายการล่าสุด (เรียงวันที่ แล้วเวลาบันทึก `created_at`)
  - ยอดคงเหลือตามแผน = ยอดเริ่ม + ให้กู้เพิ่มก่อนวันงวด − เงินต้นสะสมตามตาราง (ยอดเริ่ม = เงินต้นตามตาราง − ส่วนที่ให้กู้เพิ่มซึ่งรวมอยู่ในตารางแล้วหลัง "คำนวณงวดที่เหลือใหม่")
  - เอากล่อง "ประวัติให้กู้ / รับชำระ" ด้านล่างออก · ปรับข้อความแนะนำใต้ตาราง และในหน้าต่างแก้ไขรายละเอียด
- `financial/loans/ScheduleGrid.tsx`: หัวคอลัมน์ "เงินต้น" → "คืนเงินต้น"
