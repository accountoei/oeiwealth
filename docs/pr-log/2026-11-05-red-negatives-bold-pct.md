## กติกาที่ตกลง (เจ้าของ 5 พ.ย. 2026)
- คงเครื่องหมายลบไว้ทุกที่ (คนตาบอดสี / พิมพ์ขาวดำ) · ตัวเลขติดลบ = สีแดง · สีแดงเดิมทั้งหมดคงไว้
- ข้อยกเว้นที่ตั้งใจ: "ส่วนต่าง" ตอนอัปเดตยอดหลายบัญชี / กระทบยอด Statement = สีส้ม (คำเตือน) · ปิดเดือน ตารางบัตรเครดิต "ชำระ / คืน" = ลบสีเขียว (หนี้ลด) · บรรทัดคาดการณ์ = สีเทา
- % ในกล่องสรุปของแต่ละหน้า = ตัวหนา (เหมือน Dashboard) · คอลัมน์ % ในตาราง = ตัวปกติ
- Dashboard การ์ดสินทรัพย์: สภาพคล่องสูง % ตัวหนา สีตามระดับ < 15% แดง · 15–30% ส้ม · ≥ 30% เขียว · สภาพคล่องต่ำ % ตัวหนาสีดำ

## เปลี่ยนอะไร
- Bank Accounts กล่อง "รายการอื่นๆ": บรรทัดติดลบเป็นสีแดง · เอาคำว่า "เงินออกแสดงเป็นยอดติดลบ" ออก · % "จากเดือนก่อน" ตัวหนา
- ประกัน หน้ากรมธรรม์: "สุทธิถึงวันนี้" และคอลัมน์สุทธิสะสม ติดลบ = แดง
- การลงทุน: "พอร์ตที่ปิดแล้ว: รับรู้แล้ว" สีตามบวก/ลบ · คอลัมน์ค่าธรรมเนียมในตารางผลตอบแทน = แดง · % กำไร/ขาดทุนในกล่องสรุป ตัวหนา
- Dashboard: บรรทัดตัวหนา (ยอดตั้งต้น / ณ วันนี้) ติดลบ = แดง (หน้าหลัก + รายละเอียด)
- Private Business: "เทียบทุน" ในประวัติซื้อขายและฟอร์มขาย สีตามบวก/ลบ
- ทรัพย์สิน: "หักค่าเสื่อม" (กล่องราคาขายขั้นต่ำ + ตาราง) · "ค่าใช้จ่ายขายโดยประมาณ" · "หนี้ที่ผูกกับทรัพย์สินนี้" = แดง
- ตัวหนา %: ภาษี (อัตราเฉลี่ย) · หนี้สิน (ใช้ไป % ของวงเงิน, ชำระแล้ว %) · บัตรเครดิต · สินทรัพย์อื่น (เทียบทุน) · หลักทรัพย์ (กำไร/ขาดทุนยังไม่รับรู้) · เงินให้กู้ (สถานะการชำระเงินต้น)
