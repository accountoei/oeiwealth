## ตกลงกับเจ้าของ (6 พ.ย. 2026)
1. **แก้เงินประกันในหน้าต่าง "แก้ไขสัญญา"** ได้จนกว่าจะคืนเงินประกัน ยกไปสัญญาใหม่ หรือบันทึกผู้เช่าออก
   - ช่อง: ยอดเงินประกัน · วันที่รับ (นับเป็นหนี้สินตั้งแต่วันนี้) · บัญชีที่รับ
   - มีรายการเงินเข้า "รับเงินประกัน" อยู่แล้ว → แก้ยอด / วัน / บัญชีตามให้ · ยังไม่มี → เลือกบัญชี = บันทึกรับทีหลัง · เลือก "ไม่บันทึกเงินเข้าบัญชี" = ลบรายการ
   - รับก่อน Go-live = อยู่ในยอดบัญชีตั้งต้นแล้ว ไม่มีช่องบัญชี (เหมือนตอนสร้างสัญญา)
   - รายการเงินเข้า / ออกของเงินประกันแก้ / ลบตรงที่หน้าบัญชี / Income & Expenses ไม่ได้แล้ว (ขึ้นข้อความ "เงินประกันของสัญญาเช่า · แก้ / ยกเลิกที่สัญญาในหน้าทรัพย์สิน") เพื่อให้ยอดหนี้เงินประกันกับเงินในบัญชีตรงกันเสมอ
2. **ต่อสัญญาแล้วเงินประกันใหม่น้อยกว่าเดิมได้**: ยกมาเท่าเงินประกันใหม่ ส่วนต่างคืนผู้เช่าจากบัญชีที่เลือก ณ วันเริ่มสัญญาใหม่ (วันเดียวกับที่ยกเงินประกัน → ยอดหนี้กับเงินในบัญชีตรงกันทุกวัน)
   - รายการเงินออก "คืนเงินประกัน" ผูกกับสัญญาเดิม · การ์ดสัญญาเดิมขึ้น "ยกไปสัญญาใหม่ … · คืนส่วนต่าง …"
   - ต่อสัญญาก่อน Go-live = ไม่ต้องเลือกบัญชี (อยู่ในยอดตั้งต้นแล้ว)
   - แก้ยอดทีหลังได้ที่ "แก้ไขสัญญา" ของสัญญาใหม่ (มากกว่าเดิม = รับเพิ่ม · น้อยกว่าเดิม = คืนส่วนต่าง · ระบบปรับรายการให้) · เลื่อนวันเริ่มสัญญาใหม่ = รายการเลื่อนตาม
   - ลบสัญญาใหม่ → รายการคืนส่วนต่างถูกลบ สัญญาเดิมกลับมาถือเงินประกันเต็ม
   - ยกเงินประกันแล้วสัญญาใหม่ต้องมีเงินประกัน (ไม่เก็บแล้ว = ไม่ต้องติ๊กยก ให้คืนเงินประกันสัญญาเดิมแทน)
3. **ปุ่ม "ผู้เช่าออก / คืนเงินประกัน" ปุ่มเดียว อยู่บนการ์ดตลอด**
   - บันทึกวันออกไว้ล่วงหน้าแล้ว ยังไม่ถึงวัน → กดแล้วเห็นวันออก แก้วัน / "ยกเลิกวันออก" ได้ + ข้อความว่าคืนเงินได้ตั้งแต่วันนั้น
   - ถึงวันแล้ว → ฟอร์มเต็ม (วันออกล็อก · ADMIN กด "แก้ / ยกเลิกวันออก" ได้)
   - **สิทธิ์**: EDITOR แก้ / ยกเลิกวันออกที่บันทึกไว้ได้ก่อนถึงวันนั้น · ถึงวันแล้วเฉพาะ ADMIN (เดิม ADMIN เท่านั้น)
   - ปุ่ม "แก้วันเลิกสัญญา" ที่แยกอยู่ รวมเข้ามาในปุ่มนี้แล้ว (เหลือเฉพาะสัญญาที่เงินประกันคนละสกุลกับค่าเช่า)
4. ไม่ทำ: ค่าเสียหายในรายการส่งมอบของสัญญาที่เงินประกันคนละสกุล (ยังไม่มีสัญญาแบบนี้)
