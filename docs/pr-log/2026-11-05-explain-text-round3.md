## สาเหตุที่ตกหล่น
- ตัวค้นหารอบก่อนนับเฉพาะข้อความที่พิมพ์ไว้ในไฟล์ (ข้อความคงที่) · คำอธิบายใต้ตารางหน้าภาษีมาจากตัวแปร (`s.note`) จึงไม่ถูกนับ
- รอบนี้ค้นใหม่ 3 แบบ: (1) ข้อความเล็กสีเทาที่ไม่อยู่ในกล่อง ไม่ว่าสั้นหรือยาว คงที่หรือมาจากตัวแปร (2) ข้อความที่อยู่ถัดจากกล่อง (3) ข้อความที่อยู่ใต้ตาราง / รายการ / กล่องตัวเลข ทั้งในและนอกกล่อง แล้วดูทีละจุด

## เปลี่ยนอะไร (ข้อความ → ⓘ ข้างหัวข้อ)
- Family → Tax: คำอธิบายใต้ตารางส่วน 2 (เงินได้) · 3 (ค่าใช้จ่าย) · 4 (ค่าลดหย่อน / เงินบริจาค / ภาษีที่ชำระแล้ว) → ⓘ ข้างหัวข้อแต่ละส่วน (แบบเดียวกับส่วน 5)
- Family → Donations: กล่อง "รายจ่ายหมวดบริจาคที่ยังไม่กรอกรายละเอียด" บรรทัดบนตาราง → ⓘ ข้างหัวข้อ
- Family → หน้าสมาชิก: "ความสัมพันธ์คำนวณเทียบกับหัวหน้าครอบครัว" ใต้กล่องครอบครัว → ⓘ ข้างหัวข้อ "ครอบครัว"
- Loans ภาพรวม: หมายเหตุใต้ตาราง "สรุปเงินต้นคงเหลือตามสถานะ" และ "รายการที่ต้องติดตาม" → ⓘ ข้างหัวกล่อง (ยอดส่วนที่เสี่ยงยังแสดงในแถว "เสี่ยง" ของตาราง)
- Property แท็บค่าใช้จ่าย: กล่องภาษีที่ดิน คำอธิบายยาวใต้ชื่อกล่อง → ⓘ (เหลือบรรทัดสั้น "แสดงเต็มจำนวนของทรัพย์สินที่ … ถือ" เฉพาะตอนเลือกสมาชิก) · `LandTaxTable` เพิ่ม prop `info`
- Income & Expenses ตั้งค่า → รายได้ประจำ: "กดที่แถวเพื่อแก้ไข / ลบ" ใต้ตาราง → ⓘ ข้างหัวกล่อง (เหมือนกล่องค่าใช้จ่ายประจำ)
- Insurance แท็บความคุ้มครอง: บรรทัดใต้ตาราง → รวมเข้า ⓘ เดิมของหัวกล่อง
- Insurance หน้ากรมธรรม์: หมายเหตุใต้ "กรมธรรม์ที่ต้องติดตาม (สมาชิก Archived)" และใต้กล่อง IRR → ⓘ ข้างหัวข้อ
