## เปลี่ยนอะไร (`src/app/(app)/insurance/page.tsx` แท็บภาพรวม)
- **กล่องสรุป 4 อัน** (กรมธรรม์ที่มีผล · THB)
  1. มูลค่าเวนคืนรวม (หรือส่วนของคนที่เลือก) · บรรทัดล่าง "กรมธรรม์ที่มีผล N ฉบับ" (เลิกกล่องจำนวนกรมธรรม์แยก)
  2. ทุนประกันชีวิตรวม = ชีวิต + บำนาญ (ไม่รวมสุขภาพ ซึ่งใช้วงเงินและส่วนใหญ่เป็นเบี้ยทิ้ง) · บรรทัดล่าง "เสียชีวิตจากอุบัติเหตุ เพิ่มอีก X" เมื่อมีประกันอุบัติเหตุ
  3. เบี้ยรวมต่อปี · บรรทัดล่าง "ปีนี้ยังต้องจ่าย X" (เบี้ยงวดที่ยังจ่ายไม่ครบ ครบกำหนดไม่เกินสิ้นปีนี้ รวมงวดเลยกำหนด) + "เลยกำหนด N งวด" สีแดง
  4. ได้คืนเทียบเบี้ย % = (ผลประโยชน์ที่รับ + เงินก้อน + มูลค่าเวนคืนปัจจุบัน) ÷ เบี้ยที่จ่ายรวม (สูตรเดียวกับหน้ากรมธรรม์ รวมทุกฉบับ)
     - เฉพาะกรมธรรม์ที่มีผล มีเงินคืน (มูลค่าเวนคืน / ตารางผลประโยชน์) และมีเบี้ยที่จ่ายแล้ว · คิดทั้งกรมธรรม์ (ไม่คูณสัดส่วนเจ้าของ) · เขียวเมื่อ ≥ 100%
     - บรรทัดล่าง "เบี้ยจ่ายแล้ว X · ได้คืน Y" + "เฉพาะกรมธรรม์ที่มีเงินคืน N ฉบับ" · ไม่มีกรมธรรม์ที่เข้าเงื่อนไข = "-" พร้อมเหตุผล
- **ตาราง**: กรมธรรม์ · ประเภท (ชื่อสั้น ชีวิต / บำนาญ / สุขภาพ / อุบัติเหตุ / ทรัพย์สิน) · ผู้เอาประกัน (+ ผู้จ่าย) · ทุนประกัน · เบี้ยต่อปี · มูลค่าเวนคืน · วันเริ่มสัญญา · วันสิ้นสุดสัญญา · สถานะ
  - เลิกคอลัมน์ "เบี้ยงวดถัดไป" / "ผลประโยชน์งวดถัดไป" (มีแท็บรับ / จ่ายแล้ว) · "เบี้ยเลยกำหนด N งวด" (แดง) ย้ายไปใต้สถานะ
  - สกุลเงินแสดงเฉพาะที่ไม่ใช่ THB
- **สัญญาเพิ่มเติม**: แถวแสดง "↳ สัญญาเพิ่มเติม" (ไม่มี "เล่มเดียวกัน" แล้ว · ประเภทอยู่ในคอลัมน์ประเภท) · แถวหลักไม่มีบรรทัดที่ 2 แล้ว
  - เลิกบรรทัด "รวมทั้งเล่ม" · ส่วนสุดท้ายของเล่มต่อท้ายด้วย "· รวมทั้งเล่ม X/ปี" ตัวเล็กสีเทา (บรรทัดเดียวบนจอคอม · iPad ขึ้นบรรทัดใหม่เองเมื่อที่ไม่พอ)
- อ่านงวดประกันทีละ 1,000 แถวจนครบ (Supabase ส่งครั้งละไม่เกิน 1,000 แถว · ตอนนี้ ~800 แถว · ข้อมูลจริงเกินได้) · เลิก query งวดค้างแยก (ใช้ชุดงวดเดียวกัน) · เพิ่ม query เงินก้อนที่ไม่ผูกงวดทุกปี (ใน `Promise.all` เดิม)
